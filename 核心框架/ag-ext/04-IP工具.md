# IP 工具

> 子包：`ag/ag_ext/ip/` | package `ip`

## 功能一览

| 函数                    | 说明                   |
| --------------------- | -------------------- |
| `GetAvailablePort`    | 检查端口可用性，不可用则自动 +1 重试 |
| `IsHostAvailable`     | 检查 host 是否可达（本地/网卡）  |
| `ParseTcpIPAndPort`   | 解析 `ip:port` 字符串     |
| `NewIPRanger`         | 创建 IP 范围匹配器          |
| `IPRanger.GetLocalIP` | 获取本机网卡 IP（含范围过滤）     |

## GetAvailablePort — 端口检测

检查指定端口是否可用，不可用则自动递增重试：

```go
port, err := ip.GetAvailablePort("0.0.0.0", 8080)
if err != nil {
    // 所有端口都被占用
}
// port 可能是 8080（空闲）或 8081/8082...（被占后递增）
```

- 范围：`0` ~ `65535`
- host 不可用时返回 `ERROR_HOST_NOT_FOUND`
- 全部端口被占时返回 `ERROR_BIND_PORT_ERROR`

## IsHostAvailable — 主机检测

判断 host 是否可用：

```go
ip.IsHostAvailable("0.0.0.0")     // true（任意地址）
ip.IsHostAvailable("127.0.0.1")   // true（回环地址）
ip.IsHostAvailable("localhost")   // true
ip.IsHostAvailable("10.0.0.1")   // true（网卡匹配时）
```

检测逻辑：`0.0.0.0` / `localhost` / `127.0.0.1` 直接返回 `true`，其他地址检查是否绑定在本地网卡上。

## ParseTcpIPAndPort — 地址解析

```go
ipStr, port, err := ip.ParseTcpIPAndPort("10.0.0.1:8080")
// ipStr = "10.0.0.1", port = 8080
```

## IPRanger — IP 范围匹配

支持按配置的 IP 段过滤本机 IP：

```go
// 配置格式：逗号分隔，冒号表示范围，点号分段
// "10.250.10:10.230,10.233" 表示 10.250.10.x~10.230.x.x 和 10.233.x.x
ranger, err := ip.NewIPRanger("10.250.10:10.255")

// 获取本机符合条件的 IP
localIP, ok, err := ranger.GetLocalIP()
// 只返回在 10.250.10.0~10.255.255.255 范围内的网卡 IP

// 手动判断 IP 是否在范围内
matched := ranger.IPIsRangeAvailable("10.250.50.1")  // true
```

### IPRange 规则

| 配置示例 | 匹配范围 |
|----------|----------|
| `"10.250"` | 仅 `10.250.x.x` |
| `"10.250.10:10.250.20"` | `10.250.10.0` ~ `10.250.20.255` |
| `"10.250,10.251"` | `10.250.x.x` 或 `10.251.x.x` |
| `""`（空） | 全部 IP 通过 |

### 典型场景：多网卡服务注册

生产环境机器通常有多个网卡（`eth0` / `eth1` / `lo`...），服务组件在启动时通过 `NewIPRanger(ipRange)` 配置期望的 IP 段范围。`GetLocalIP()` 从所有网卡中筛选出**第一个**落在范围内的 IP，作为**服务注册地址**上报给注册中心（etcd / Nacos / Consul），确保上下游调用指向正确的网络平面。

```go
// 配置文件指定：IPRange: "10.250"
ranger, _ := ip.NewIPRanger("10.250")
serviceIP, ok, err := ranger.GetLocalIP()
// serviceIP = "10.250.10.5"  ← 忽略 192.168.x.x 和 127.0.0.1
registry.Register(serviceIP, port)
```

如果未配置 `IPRange`（空字符串 `""`），则接受所有网卡 IP，取第一个可用地址。

## 调用方

| 调用者          | 用途                              |
| ------------ | ------------------------------- |
| 框架 Server 启动 | `GetAvailablePort` 检测服务端口       |
| 多网卡部署        | `IPRanger` 过滤绑定地址               |
| 服务注册         | `NewIPRanger` + `GetLocalIP` 在多网卡下筛选正确 IP 上报 |
