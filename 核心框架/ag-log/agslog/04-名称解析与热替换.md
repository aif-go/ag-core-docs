# 名称解析与热替换

agslog 的核心机制是「通过名称解析 handler」和「运行时替换 handler」。

## 名称解析体系

agslog 中有三层缓存，每层都有不同用途：

### 三层缓存

| 缓存 | 类型 | Key | 用途 | 被谁写入 | 被谁读取 |
|------|------|-----|------|----------|----------|
| `handlersCaches` | `sync.Map` | handler 名称 | 存储**原始 handler**（未经中间件和 NamedHandler 包装） | `addHandler()` | `resolveHandler()` |
| `handlers` | `sync.Map` | handler 名称 | 存储**完整 handler**（经过中间件和 NamedHandler 包装） | `getNamedHandler()` | `getNamedHandler()` |
| `namedLogger` | `sync.Map` | logger 名称 | 缓存已创建的 `*slog.Logger` 实例 | `GetSlogByName()` | `GetSlogByName()` |
| `replaceableHandllers` | `sync.Map` | handler 名称 | 存储 Build 前创建的 `*ReplaceableHandler`，用于后置替换 | `GetSlogByName()` | `tryReplaceNamedHandler()` |

### resolveHandler — 获取原始 handler

```go
func (b *Builder) resolveHandler(hname string) (slog.Handler, error) {
    // 第一步：从 handlersCaches 查找
    if handler, ok := b.handlersCaches.Load(hname); ok {
        return handler.(slog.Handler), nil
    }

    // 第二步：遍历 factories，按名称匹配
    for _, f := range b.factories {
        if f.Name == hname {
            handler, err := f.GetHandler(b.resolveHandler)  // ★ 递归
            b.handlersCaches.Store(hname, handler)
            return handler, nil
        }
    }

    return nil, fmt.Errorf("handler %s not found", hname)
}
```

**递归解析**：factory 的 `DoGetHandler` 会接收 `resolveHandler` 作为参数，用于获取子 handler（如 fanout 中获取底层 zap handler）。

**缓存写入**：解析成功后立即写入 `handlersCaches`，后续同名解析直接命中。

### getNamedHandler — 获取完整 handler

```go
func (b *Builder) getNamedHandler(hname string) INamedHandler {
    // 第一步：从 handlers 缓存查找
    if handler, ok := b.handlers.Load(hname); ok {
        return handler.(INamedHandler)
    }

    // 第二步：resolveHandler 解析原始 handler
    rh, err := b.resolveHandler(hname)
    if err != nil {
        return nil  // 解析失败，调用方自行处理降级
    }

    // 第三步：应用中间件
    if len(b.middlewares) > 0 {
        rh = slogmulti.Pipe(b.middlewares...).Handler(rh)
    }

    // 第四步：确保有 NamedHandler 包装
    handler := b.wrapNamedHandlerIfNeed(hname, rh)

    // 第五步：缓存到 handlers
    b.handlers.Store(hname, handler)
    return handler.(INamedHandler)
}
```

### GetSlogByName — 获取 Logger（DCLP 模式）

```go
func (b *Builder) GetSlogByName(hname string) *slog.Logger {
    // 无锁检查
    if logger, ok := b.namedLogger.Load(hname); ok {
        return logger.(*slog.Logger)
    }

    // 加锁 + 双重检查（DCLP）
    b.logMu.Lock()
    defer b.logMu.Unlock()

    if logger, ok := b.namedLogger.Load(hname); ok {
        return logger.(*slog.Logger)
    }

    // 获取 handler
    var handler slog.Handler
    handler = b.getNamedHandler(hname)
    if handler == nil {
        // 降级：使用 TopLogger 的 handler
        blogger := TopLogger()
        if hname == topLoggerName || blogger == nil {
            blogger = slog.Default()
        }
        handler = blogger.Handler()
    }

    // 包装为 ReplaceableHandler（支持后续热替换）
    handler = NewReplaceableHandler(hname, handler)

    // 非 topLoggerName 的 handler 存入 replaceableHandllers
    if hname != topLoggerName {
        b.replaceableHandllers.Store(hname, handler)
    }

    // 创建 Logger
    logger := slog.New(handler)
    b.namedLogger.Store(hname, logger)
    return logger
}
```

## 热替换机制

### 触发时机

热替换发生在 `Builder.Build()` 的最后一步：

```go
func (b *Builder) Build() (*slog.Logger, error) {
    logger, err := b.initTopLogger()     // ① 替换 TopLogger 的 handler
    if err != nil { return nil, err }

    b.tryReplaceNamedHandler()           // ② 替换所有已创建 Logger 的 handler
    return logger, nil
}
```

### 替换 TopLogger

见 [TopLogger 生命周期](02-TopLogger生命周期.md) 第三阶段。

核心代码：

```go
thandler := topLog.Handler()                // 获取 ReplaceableHandler
th, ok := thandler.(*ReplaceableHandler)
if ok && !th.IsMatchesName() {
    th.ReplaceHandler(rhandler)             // 原子替换内部指针
}
```

`IsMatchesName()` 检查当前内部 handler 名称是否已经是目标名称。如果是，说明已被替换过，跳过。

### 替换其他 Logger

```go
func (b *Builder) tryReplaceNamedHandler() {
    b.replaceableHandllers.Range(func(k, v any) bool {
        if k == topLoggerName { return true }

        rh, ok := v.(*ReplaceableHandler)
        if !ok { return true }
        if rh.IsMatchesName() { return true }  // 已匹配，跳过

        name := rh.Name()
        h, err := b.resolveHandler(name)       // 重新解析
        if err != nil {
            th := TopLogger().Handler()
            h = th                              // 降级到 TopLogger
        }

        rh.ReplaceHandler(h)
        return true
    })
}
```

**为什么要遍历所有 replaceableHandllers？**

因为 Build **之前**可能已经通过 `GetSlogByName` 创建了多个 Logger。这些 Logger 的 handler 此时指向的是「降级 handler」（如 slog.Default 或 TopLogger 的旧 handler）。`tryReplaceNamedHandler` 将它们全部修正为正确的 handler。

### 替换过程示意

假设有如下配置和调用时序：

```
调用时序：
  1. init → TopLogger(占位)
  2. loggerA := GetSlogByName("f1")      // 创建 f1 Logger
  3. loggerB := GetSlogByName("f2")      // 创建 f2 Logger
  4. builder.Build()
       ├─ initTopLogger():
       │     f1 解析 → zap1（已注册到工厂）
       │     TopLogger.handler.Replace(f1_handler)
       │
       └─ tryReplaceNamedHandler():
             ├─ "f1": IsMatchesName? 否 → 解析为真实 f1 → rh.Replace(f1_handler)
             └─ "f2": IsMatchesName? 否 → 解析为真实 f2 → rh.Replace(f2_handler)
```

替换后：

```
loggerA (同一个指针)
  └── Handler: ReplaceableHandler("f1")  ← 内部指针已替换为
        └── NamedHandler("f1")
              └── Fanout(zap1, zap2)

loggerB (同一个指针)
  └── Handler: ReplaceableHandler("f2")  ← 内部指针已替换为
        └── NamedHandler("f2")
              └── Fanout(
                    └── NamedHandler("f1")
                          └── Fanout(zap1, zap2)
                  )
```

**loggerA 和 loggerB 的引用不需要更新，它们的 Handler() 方法每次调用都通过 atomic.Load 获取最新内部 handler。**

### 替换后的状态检查

```go
// 检查 handler 是否已被正确替换
handler := loggerA.Handler()
if rh, ok := handler.(*agslog.ReplaceableHandler); ok {
    if rh.IsMatchesName() {
        fmt.Println("handler 已被替换为正确的匹配")
    }
}
```

## 关键细节总结

| 场景 | 行为 |
|------|------|
| Build 前 GetSlogByName | 创建 ReplaceableHandler，内部指向降级 handler |
| Build 后 GetSlogByName | 创建 ReplaceableHandler，内部指向正确 handler |
| Build 后首次 GetSlogByName | 直接从 namedLogger 缓存返回（前次 Build 后创建） |
| tryReplaceNamedHandler 遍历 | 只替换 Build 前创建的 logger，Build 后的已天然正确 |
| WithAttrs/WithGroup 派生 | 快照当前 handler，**不受后续替换影响** |
| 解析失败降级 | `tryReplaceNamedHandler` 中 fall back 到 TopLogger handler |
