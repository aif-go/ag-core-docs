# FX 集成 — 模块装配与配置绑定

> 文件：`ag/ag_log/zfx_aglog.go` + 各子包 `zfx_*.go`

## 概述

ag-log 通过 Uber FX 实现依赖注入。所有子模块通过 **group tags** 注册 handler/factory/middleware，由 `agslog.Builder` 统一收集和装配。

## 顶层 FX Module

```go
var FxAglogMode = fx.Module("ag_log",
    agslog.FxAgSlogProvide,       // agslog 核心
    fanout.FxAgSlogFanoutProvide, // fanout 扇出
    async.FxAglogAsyncProvide,    // 异步日志
    slogzap.FxAgSlogZapProvide,   // slog↔zap 桥接
    fx.Invoke(func(logger *slog.Logger) {
        logger.Info("slog is ready")
    }),
)
```

一行引入即可完成完整日志系统装配：

```go
fxapp := fx.New(
    fxs.FxAgConfModule,
    ag_log.FxAglogMode,
)
```

## 各子模块 Provide

### agslog — 核心提供器

```go
var FxAgSlogProvide = fx.Provide(
    BindAgSlogProperties,   // 绑定 aglog.* 配置
    FxBuildAgSlogBuilder,   // 收集所有组件 → Builder
    FxBuildTopLog,          // Builder.Build() → *slog.Logger
)
```

**`FxBuildAgSlogBuilder`** 通过 group tags 注入：

```go
func FxBuildAgSlogBuilder(params FxInAgSlogBuilderParams) (*Builder, error) {
    // params 自动收集以下 group 标签的内容：
    //   agslog.handler    → []slog.Handler         （直接注册的 handler）
    //   agslog.handlers   → [][]slog.Handler       （批量注册）
    //   agslog.factory    → []*HandlerFactory        （工厂）
    //   agslog.factorys   → [][]*HandlerFactory      （批量工厂）
    //   agslog.middleware → []slogmulti.Middleware   （中间件）
}
```

### fanout — 扇出提供器

```go
var FxAgSlogFanoutProvide = fx.Provide(
    BindAgSLogFanoutProperties,   // 绑定 aglog.fanout.*
    fx.Annotate(
        NewFanoutHandlerFactorys, // 生成 []*HandlerFactory
        fx.ResultTags(`group:"agslog.factorys"`),
    ),
)
```

### async — 异步提供器

```go
var FxAglogAsyncProvide = fx.Provide(
    BindAsyncLogConfig,           // 绑定 aglog.async.*
    fx.Annotate(
        BuildAsyncHandlerFactorys, // 生成 []*HandlerFactory
        fx.ResultTags(`group:"agslog.factorys"`),
    ),
)
```

### slogzap — Zap 桥接提供器

```go
var FxAgSlogZapProvide = fx.Provide(
    BindSlogZapProperties,        // 绑定 aglog.zap.*
    fx.Annotate(
        NewSlogHandler4ZapProps,  // 生成 []slog.Handler
        fx.ResultTags(`group:"agslog.handlers"`),
    ),
)
```

## 装配流程

```
FX Container 启动
│
├── BindAgSlogProperties       → aglog.* 配置
├── BindAgSLogFanoutProperties → aglog.fanout.* 配置
├── BindAsyncLogConfig         → aglog.async.* 配置
├── BindSlogZapProperties      → aglog.zap.* 配置
│
├── NewSlogHandler4ZapProps    → [][]slog.Handler  (group: agslog.handlers)
├── NewFanoutHandlerFactorys   → [][]*HandlerFactory (group: agslog.factorys)
├── BuildAsyncHandlerFactorys  → [][]*HandlerFactory (group: agslog.factorys)
│
├── FxBuildAgSlogBuilder(params) → *Builder
│     ├── WithProperties(aglog.*)
│     ├── AddHandlerss(zap handlers)
│     ├── AddHandlerFactoryss(fanout factories + async factories)
│     └── (支持 AddMiddlewares — 扩展点)
│
└── FxBuildTopLog(builder)     → *slog.Logger
      ├── builder.Build()
      ├── resolveTopHandlers()  — 按名称从配置/工厂解析
      ├── fanout/pipe/包装
      └── slog.SetDefault()    — 可选
```

## group tags 一览

| Group Tag | 类型 | 来源 | 用途 |
|-----------|------|------|------|
| `agslog.handler` | `[]slog.Handler` | 外部代码、`NewSlog4Zap` | 单个注册 |
| `agslog.handlers` | `[][]slog.Handler` | `NewSlogHandler4ZapProps` | 批量注册 |
| `agslog.factory` | `[]*HandlerFactory` | — | 单个工厂 |
| `agslog.factorys` | `[][]*HandlerFactory` | fanout、async | 批量工厂 |
| `agslog.middleware` | `[]slogmulti.Middleware` | — | 中间件（扩展点）|

## 扩展：自定义处理器

通过 FX group tags 注册自定义 handler：

```go
fx.Provide(
    fx.Annotate(
        func() slog.Handler {
            return slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{})
        },
        fx.ResultTags(`group:"agslog.handler"`),
    ),
)
```

注册自定义中间件：

```go
fx.Provide(
    fx.Annotate(
        func() slogmulti.Middleware {
            return func(next slog.Handler) slog.Handler {
                return &myMiddleware{next: next}
            }
        },
        fx.ResultTags(`group:"agslog.middleware"`),
    ),
)
```

## 注意事项

| 要点 | 说明 |
|------|------|
| **提供顺序** | `FxAglogMode` 已按正确依赖顺序编排，使用者只需一行导入 |
| **配置容错** | fanout、slogzap、async 的绑定失败均返回 `nil`，不阻塞应用启动 |
| **重复注册** | handler 同名会报错（`already registered`），注意配置中的名称唯一性 |
| **灵活组合** | 不需要 fanout 时可以只引入 `agslog.FxAgSlogProvide` + `slogzap.FxAgSlogZapProvide` |
| **中间件扩展** | `agslog.middleware` group 是预留的扩展点，可用于日志过滤/脱敏/增强 |
