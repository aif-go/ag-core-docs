# 🧱 核心框架 — ag/

ag-core 的核心框架层，位于 `ag/` 目录。提供微服务运行所需的基础设施。

## 模块一览

| 模块 | 包路径 | 说明 |
|------|--------|------|
| [[ag-app/00-AgApp\|App 应用启动器]] | `ag/ag_app/` | 统一入口，管理服务器生命周期 |
| [[ag-conf/00-AgConf-概览\|AgConf 配置管理]] | `ag/ag_conf/` | 多属性源、占位符解析、绑定、热更新、解密 [[ag-conf/09-与Spring对比\|🐍]] |
| [[ag-server/00-AgServer\|AgServer 服务端抽象]] | `ag/ag_server/` | Gin/HTTP 服务端封装 |
| [[ag-service/00-AgService\|AgService 服务注册]] | `ag/ag_service/` | 服务注册与发现抽象 |
| [[ag-error/00-AgError\|AgError 错误处理]] | `ag/ag_error/` | 业务状态码与错误封装 |
| [[ag-crypto/00-AgCrypto\|AgCrypto 加密]] | `ag/ag_crypto/` | AES/RSA 等加解密工具 |
| [[ag-common/00-AgCommon\|AgCommon 公共工具]] | `ag/ag_common/` | 切片、字符串等通用工具 |
| [[ag-ext/00-AgExt\|AgExt 扩展]] | `ag/ag_ext/` | 可插拔扩展接口 |
| [[ag-log/00-AgLog\|AgLog 日志]] | `ag/ag_log/` | 日志封装 |

## 调用关系

```
App.Start()
  ├── 加载配置 (AgConf)
  ├── 初始化服务器 (AgServer)
  ├── 注册服务 (AgService)
  ├── 应用扩展 (AgExt)
  └── 启动监听
```

## 关键设计

- 采用 **Options 模式**（`WithXXX()` 函数）进行配置
- 模块间通过 **接口依赖**，而非具体类型
- 支持 **多配置文件合并**（主配置 + 环境特定配置）
- 属性占位符支持 `${...}` 和 `{{...}}` 两种语法
