## 快速开始 — 完整的最小应用

### 第 1 步：写 main.go

```go
package main

import (
    "gitlab.allinfinance.com/aifgo/ag-core/ag/ag_log"
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    "go.uber.org/fx"
)

func main() {
    fx.New(
        fxs.FxAgConfModule,         // 配置加载
        ag_log.FxAglogMode,         // 日志系统
        fxs.FxHttpServerBaseModule, // HTTP 服务
        fxs.FxAppMode,              // 应用容器
    ).Run()
}
```

### 第 2 步：写配置文件

`app.yml`（放在可执行文件同目录下）：

```yaml
http:
  host: 0.0.0.0
  port: 8080

aglog:
  isDefault: true
  topHandler:
    - "console"
  zap:
    logs:
      console:
        log_level: info
        stdout: true
        console: true
```

### 第 3 步：运行

```bash
go run main.go
```

访问 `http://localhost:8080` — Gin 返回 404（未注册路由）。下一步添加接口。

## 添加 HTTP 接口

### 在 Provide 中注册路由

```go
fx.Provide(
    func(s *http.Server) *http.Server {
        s.GET("/api/hello", func(c *gin.Context) {
            c.JSON(200, gin.H{
                "message": "Hello, World!",
                "version": "1.0.0",
            })
        })
        s.GET("/api/health", func(c *gin.Context) {
            c.JSON(200, gin.H{"status": "ok"})
        })
        return s
    },
)
```

### 完整文件

```go
package main

import (
    "gitlab.allinfinance.com/aifgo/ag-core/ag/ag_log"
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    "github.com/gin-gonic/gin"
    "go.uber.org/fx"
)

func main() {
    fx.New(
        fxs.FxAgConfModule,
        ag_log.FxAglogMode,
        fxs.FxHttpServerBaseModule,

        // 注册路由
        fx.Provide(
            func(s *http.Server) *http.Server {
                registerRoutes(s)
                return s
            },
        ),

        fxs.FxAppMode,
    ).Run()
}

func registerRoutes(r *gin.Engine) {
    r.GET("/api/hello", func(c *gin.Context) {
        c.JSON(200, gin.H{"message": "hello"})
    })
    r.GET("/api/health", func(c *gin.Context) {
        c.JSON(200, gin.H{"status": "ok"})
    })
}
```

## 添加多个服务

一个 App 可以同时运行多个 Server（如 HTTP + gRPC + 配置热更新）：

```go
fx.New(
    fxs.FxAgConfModule,
    ag_log.FxAglogMode,

    // HTTP 服务
    fxs.FxHttpServerBaseModule,

    // 自定义 gRPC 服务
    fx.Provide(
        fx.Annotate(
            NewGrpcServer,              // 返回 *grpc.Server 或自定义类型
            fx.As(new(ag_server.Server)), // 转为 Server 接口
            fx.ResultTags(`group:"ag_servers"`), // 注入 group
        ),
    ),

    fxs.FxAppMode,
).Run()
```

每个 Server 会：
- 在 `App.Start()` 时在自己的 goroutine 中启动
- 在 `App.Stop()` 时串行关闭

## 使用 FX 模式（推荐）

### 标准启动结构

```go
// main.go
package main

import (
    "gitlab.allinfinance.com/aifgo/ag-core/ag/ag_log"
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    "go.uber.org/fx"
)

func main() {
    fx.New(
        // === 基础设施 modules ===
        fxs.FxAgConfModule,     // 配置加载（必须）
        ag_log.FxAglogMode,     // 日志系统（必须）

        // === 服务 modules ===
        fxs.FxHttpServerBaseModule,  // HTTP 服务
        // 你的业务模块...
        // YourBusinessModule,

        // === 应用容器（必须最后） ===
        fxs.FxAppMode,
    ).Run()
}
```

### 业务模块写法

```go
// user/module.go
package user

import (
    "gitlab.allinfinance.com/aifgo/ag-core/ag/ag_server"
    "github.com/gin-gonic/gin"
    "go.uber.org/fx"
)

var Module = fx.Module("user",
    fx.Provide(
        // 注册路由
        func(s *http.Server) *http.Server {
            s.GET("/api/users", listUsers)
            s.POST("/api/users", createUser)
            return s
        },
        // 可以在这里 Provide 业务 Service
        NewUserService,
    ),
)
```

```go
// main.go 引入
import "your-project/user"

fx.New(
    fxs.FxAgConfModule,
    ag_log.FxAglogMode,
    fxs.FxHttpServerBaseModule,
    user.Module,          // ★ 引入业务模块
    fxs.FxAppMode,
).Run()
```

## 配置文件中的服务参数

### HTTP 服务

```yaml
http:
  host: 0.0.0.0          # 监听地址
  port: 8080             # 监听端口
```

### 日志

```yaml
aglog:
  isDefault: true
  topHandler:
    - "console"
  zap:
    logs:
      console:
        log_level: info
        stdout: true
        console: true
      file:
        log_level: info
        log_file_name: "logs/app.log"
        max_size: 512
```

### 环境变量覆盖

```bash
# 覆盖 HTTP 端口
export HTTP_PORT=9090
# 覆盖日志级别
export ALOG_ZAP_LOGS_CONSOLE_LOG_LEVEL=debug
```

## 代码组织结构建议

```
my-service/
├── main.go                  ← 仅模块装配
├── app.yml                  ← 配置文件
├── internal/
│   ├── user/
│   │   ├── module.go        ← fx.Module("user")
│   │   ├── handler.go       ← Gin handler
│   │   ├── service.go       ← 业务逻辑
│   │   └── config.go        ← 配置结构体
│   ├── order/
│   │   ├── module.go
│   │   ├── handler.go
│   │   └── service.go
│   └── pkg/
│       └── ...
└── go.mod
```

**main.go 示例：**

```go
package main

import (
    "gitlab.allinfinance.com/aifgo/ag-core/ag/ag_log"
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    "your-project/internal/user"
    "your-project/internal/order"
    "go.uber.org/fx"
)

func main() {
    fx.New(
        fxs.FxAgConfModule,
        ag_log.FxAglogMode,
        fxs.FxHttpServerBaseModule,
        user.Module,
        order.Module,
        fxs.FxAppMode,
    ).Run()
}
```

## 常见问题

### Q：启动后访问端口没反应？

检查：
1. `app.yml` 中是否配置了 `http.host` 和 `http.port`
2. 是否已注册路由（Gin 默认返回 404）
3. 端口是否被占用

### Q：如何获取配置参数？

```go
// 在 FX Provide 中注入 IConfigurableEnvironment
fx.Provide(
    func(env ag_conf.IConfigurableEnvironment) *MyConfig {
        host := env.GetProperty("http.host")
        port := env.GetProperty("http.port")
        // ...
    },
)
```

### Q：如何自定义 Gin 配置？

```go
fx.Decorate(func() *gin.Engine {
    gin.SetMode(gin.ReleaseMode)  // 生产模式
    r := gin.New()                // 不使用默认中间件
    r.Use(gin.Recovery())         // 自定义中间件
    return r
})
```

### Q：Server 启动失败会怎样？

目前使用 `log.Fatal()` 直接退出。建议在 Server 的 `Start()` 中做好启动前置检查。

### Q：开发环境需要热重启吗？

修改代码后 `Ctrl+C` 停止，重新 `go run main.go` 启动。生产环境建议使用 Docker + 健康检查。
