# FX 集成 — 依赖注入装配

> 源码：`fxs/zfx_*.go`

## 概述

ag-app 通过 Uber FX 实现完整的依赖注入式启动。应用只需通过 `fx.Module` 声明依赖，框架自动完成配置加载、日志装配、服务注册和生命周期管理。

## FxApp — 主构造器

```go
func FxApp(params FxAppParams, lc fx.Lifecycle) *ag_app.App {
    app := &ag_app.App{
        Servers: params.Servers,     // 通过 group tag 注入
        Logger:  params.Logger,      // 通过 DI 注入
    }
    lc.Append(fx.Hook{
        OnStart: func(ctx context.Context) error {
            return app.Start(ctx)    // 挂到 FX 生命周期
        },
        OnStop: func(ctx context.Context) error {
            app.Stop(ctx)
            return nil
        },
    })
    return app
}
```

### 注入参数

```go
type FxAppParams struct {
    fx.In
    Servers []ag_server.Server `group:"ag_servers"`  // 服务列表
    Logger  *slog.Logger                             // 日志实例
}
```

- **Servers**：通过 `group:"ag_servers"` 聚合所有 Server 实现
- **Logger**：由 `FxAglogMode` 提供

### 生命周期

```
FX.Start()
  │
  ├─ 按依赖顺序构造所有 Provide
  │    ├─ FxAgConfModule    → env, binder, watcher
  │    ├─ FxAglogMode       → logger
  │    ├─ FxHttpServerBase  → http.Server（加入 ag_servers group）
  │    └─ FxApp             → ag_app.App
  │
  ├─ 执行 Invoke
  │
  └─ 执行 OnStart Hook
       └─ app.Start(ctx)
            ├─ 注意：此 ctx 是 FX 的 Start 上下文，有超时控制
            ├─ 但 App.Start 内部会创建独立的 context.Background()
            └─ 所有 Server 在 goroutine 中启动
```

```
FX.Stop()
  │
  └─ 执行 OnStop Hook（逆序）
       └─ app.Stop(ctx)
            └─ 逐个串行关闭 Server
```

## 各 FX Module

### FxAgConfModule — 配置加载

```go
var FxAgConfModule = fx.Module("ag_conf",
    fx.Provide(
        // 1. 创建 Environment
        NewStandardEnvironment → IConfigurableEnvironment
        // 2. 加载本地配置
        LoadLocalConfigToState → LocalConfigLoded（控制顺序）
        // 3. 创建 Binder（依赖 LocalConfigLoded，确保配置先加载）
        NewConfigurationPropertiesBinder → IBinder
    ),
    // 内嵌：配置热更新 Server（也注册为 ag_servers）
    // 将 WatcherServer 注入 group: ag_servers
)
```

### FxHttpServerBaseModule — HTTP 服务

```go
var FxHttpServerBaseModule = fx.Module("fx_http_server_base",
    fx.Provide(
        // 提供 http.Server（非接口）
        http.NewHttpGinServer,
        // 包装为 ag_server.Server，注入 group: ag_servers
        fx.Annotate(
            httpserverWrapper,
            fx.ResultTags(`group:"ag_servers"`),
        ),
    ),
)
```

### FxHelloServerMode — Hello 服务

```go
var FxHelloServerMode = fx.Module("helloServer",
    fx.Provide(
        fx.Annotate(
            hello.NewHelloServer,
            fx.As(new(ag_server.Server)),
            fx.ResultTags(`group:"ag_servers"`),
        ),
    ),
)
```

见 [ag-log FX 集成](../ag-log/05-FX集成.md)。

## 完整应用示例

### 最小 FX 应用

```go
package main

import (
    "gitlab.allinfinance.com/aifgo/ag-core/ag/ag_log"
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    "go.uber.org/fx"
)

func main() {
    fx.New(
        fxs.FxAgConfModule,           // 配置
        ag_log.FxAglogMode,           // 日志
        fxs.FxHttpServerBaseModule,   // HTTP 服务
        fxs.FxAppMode,                // App 容器
    ).Run()
}
```

### 添加自定义 Server

```go
fx.Provide(
    fx.Annotate(
        NewMyGrpcServer,
        fx.As(new(ag_server.Server)),
        fx.ResultTags(`group:"ag_servers"`),
    ),
)
```

### 自定义路由

```go
// 在 Provide 阶段注册路由
fx.Provide(
    func(s *http.Server) *http.Server {
        s.GET("/api/hello", func(c *gin.Context) {
            c.JSON(200, gin.H{"msg": "hello"})
        })
        return s
    },
)
```

## group tags 一览

| Group Tag | 类型 | 来源 | 用途 |
|-----------|------|------|------|
| `ag_servers` | `[]ag_server.Server` | 各 Server Module | 聚合所有服务 |
| `agslog.handler` | `[]slog.Handler` | 日志模块 | 注册日志处理器 |
| `agslog.factorys` | `[][]*agslog.HandlerFactory` | 日志模块 | 注册日志工厂 |

## 注意事项

| 要点 | 说明 |
|------|------|
| **Server 注册** | 必须使用 `fx.ResultTags('group:"ag_servers"')` 注入 group |
| **接口转换** | `*http.Server` 不是 `ag_server.Server`，需通过 `As()` 或 `fx.Annotate` 桥接 |
| **启动不等待** | `App.Start()` 启动 goroutine 后立即返回，不确认服务已就绪 |
| **配置热更新** | `FxAgConfModule` 内嵌了 WatcherServer，自动注册为服务 |
