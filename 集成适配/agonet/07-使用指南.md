## 快速开始

### 方式一：核心层 EventHandler（简单场景）

```go
import (
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet"
)

// 1. 实现 EventHandler
type EchoHandler struct {
    agonet.BuiltinEventEngine  // 内嵌空实现
}

func (h *EchoHandler) OnTraffic(c agonet.Conn) (action agonet.Action) {
    // 读取数据
    buf, err := c.Next(c.InboundBuffered())
    if err != nil {
        return agonet.Close
    }
    // 写回数据
    c.Write(buf)
    c.Flush()
    return
}

// 2. 启动服务器
func main() {
    handler := &EchoHandler{}
    config := agonet.DefaultServerConfig()
    config.Addr = "tcp://:9000"

    server, _ := agonet.NewServer(handler, &config)
    server.Start()  // 阻塞
}
```

### 方式二：Simple 管道层（推荐）

```go
import (
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet/simple"
)

// 1. 定义 Handler
type EchoHandler struct {
    simple.SimpleHandler
}

func (h *EchoHandler) ChannelRead(ctx simple.ChannelHandlerContext, msg any) error {
    reader := msg.(agonet.Reader)
    data, _ := reader.Next(reader.InboundBuffered())
    // 写回
    ctx.Write(data)
    // 传播到下一个 Handler（如果有）
    return ctx.Next()
}

// 2. 创建 EventHandler
handler, _ := simple.NewSimpleEventHandlerWithOptions(
    simple.WithChannelInitializer(func(channel simple.Channel) error {
        channel.Pipeline().AddLast(&EchoHandler{})
        return nil
    }),
)

// 3. 启动
server, _ := agonet.NewServer(handler, &config)
server.Start()
```

## 配置示例

### 最小 TCP 服务端

```yaml
addr: "tcp://:9000"
config:
  engine:
    multicore: true
```

### TLS 服务端

```yaml
addr: "tcp://:9443"
config:
  security:
    type: tls
    certsDir: /etc/certs
    tls:
      caPath: ca.crt
      authCertPath: server.crt
      authKeyPath: server.key
```

### TLCP（国密）服务端

```yaml
addr: "tcp://:9443"
config:
  security:
    type: tlcp
    certsDir: /etc/certs
    tlcp:
      caPath: sm2-ca.cer
      authCertPath: sm2-auth.cer
      authKeyPath: sm2-auth.key
      signCertPath: sm2-sign.cer
      signKeyPath: sm2-sign.key
      encCertPath: sm2-enc.cer
      encKeyPath: sm2-enc.key
```

### 双栈服务端（同时支持 TLS + TLCP）

```yaml
addr: "tcp://:9443"
config:
  security:
    type: tls_tlcp
    certsDir: /etc/certs
    tls:
      caPath: ca.crt
      authCertPath: server.crt
      authKeyPath: server.key
    tlcp:
      caPath: sm2-ca.cer
      authCertPath: sm2-auth.cer
      authKeyPath: sm2-auth.key
      signCertPath: sm2-sign.cer
      signKeyPath: sm2-sign.key
      encCertPath: sm2-enc.cer
      encKeyPath: sm2-enc.key
```

## Simple 管道模式示例

### LengthField 编解码（自定义协议）

```go
handler, _ := simple.NewSimpleEventHandlerWithOptions(
    simple.WithChannelInitializer(func(channel simple.Channel) error {
        channel.Pipeline().AddLast(
            // 入站：LengthField 拆包（前 4 字节为长度）
            &simple.LengthFieldDecoder{
                MaxFrameLength:    1024 * 1024,
                LengthFieldOffset: 0,
                LengthFieldLength: 4,
                LengthAdjustment:  0,
                InitialBytesToStrip: 4,
            },
            // 业务 Handler
            &BizHandler{},
        )
        return nil
    }),
)
```

## FX 集成

```go
import (
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet/simple"
)

func main() {
    app := fxs.FxAppMode(
        fxs.FxAgConfModule,

        // Server
        fx.Provide(
            func() agonet.EventHandler {
                handler, _ := simple.NewSimpleEventHandlerWithOptions(...)
                return handler
            },
        ),
        agonet.FxAgonetServerModule,

        // 简单客户端
        fx.Provide(
            simple.FxAgonetSimpleGroupTag(func() simple.ShortClientOption {
                return simple.WithShortClientTimeout(5 * time.Second)
            }),
        ),
    )
    app.Run()
}
```

## 最佳实践

### ✅ Simple 管道层优先

除极简单场景外，优先使用 `simple` 管道层。它将事件驱动转换为 Handler 链，便于分离编解码和业务逻辑。

### ✅ 按需求选择 EventLoop 数量

```yaml
engine:
  multicore: true      # = NumCPU，大部分场景适用
  numEventLoop: 4      # 手动指定（如 IO 密集型业务）
```

### ✅ 合理配置 KeepAlive

```yaml
keepAlive:
  enable: true
  idle: 60        # 60 秒无数据开始探测
  interval: 12    # 每 12 秒探测一次
  count: 5        # 5 次失败断开（共 60s 探测周期）
```

### ❌ Handler 中不要做阻塞操作

EventHandler 和 Handler 都在 EventLoop 的 goroutine 中执行，阻塞操作会阻塞整个 EventLoop。

```go
func (h *Handler) ChannelRead(ctx, msg) error {
    // ❌ 不要这样做
    result := heavyDatabaseQuery(msg)
    ctx.Write(result)

    // ✅ 使用 ctx.Executor() 异步执行
    ctx.Executor().Execute(func() {
        result := heavyDatabaseQuery(msg)
        ctx.Write(result)
    })
    return nil
}
```

### ❌ 不要直接读写 Conn 的 net.Conn

```go
// ❌ 直接读写底层连接会导致不可预知后果
c.NetConn().Read(buf)

// ✅ 通过 Conn 接口提供的方法
c.Next(n)
c.Write(data)
c.Flush()
```

## FAQ

**Q: 支持哪些传输协议？**
A: `tcp`、`tcp4`、`tcp6`、`udp`、`udp4`、`udp6`、`unix`。

**Q: TLS 和 TLCP 如何选择？**
A: 标准安全通信用 `tls`；遵循国家密码标准的场景用 `tlcp`。双栈模式 `tls_tlcp` 可同时监听两种协议。

**Q: 如何获取连接统计数据？**
A: 通过 `Conn.PoolStats()`（如适用）或自定义 Handler 统计。

**Q: ShortClient 和长连接的适用场景？**
A: `ShortClient` 每次请求创建新连接（Promise 模式），适合请求频率低、需要简单 API 的场景。高频通信建议基于 `EventHandler.OnOpen` 管理长连接。
