# 客户端 — 长连接与短连接

> 路径：`agonet/client.go` + `simple/short_client.go`

Simple 管道层为客户端也提供了完整的 Pipeline 和 Codec 支持，两种连接模式都基于 Simple 封装构建：

| 模式 | 推荐方式 | 连接管理 | 适用场景 |
|------|---------|---------|---------|
| **长连接** | `agonet.Client.Dial` + 保持 Conn + SimpleEventHandler | 持久连接，Pipeline 持续活跃 | 高频通信、实时推送、网关 |
| **短连接** | `SimpleShortClient.RequestSync` | 每次请求建连→发→收→关 | 管理命令、健康检查、偶发请求 |

纯 `agonet.Client` 直连（不使用 Simple）保留作为底层通道，但**业务场景应优先使用 Simple 封装**，以获取 Pipeline 链式处理、编解码器（半包/粘包处理）、异常链传播等能力。

---

## 一、长连接

长连接通过 `agonet.Client` 建立持久 TCP 连接，保持 Conn 以避免每次通信的三次握手开销。数据流经 Simple 的 Pipeline 链处理。

### 创建

```go
import (
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet/simple"
)

// 1. 创建 SimpleEventHandler（服务端/客户端都适用）
handler, _ := simple.NewSimpleEventHandlerWithOptions(
    simple.WithChannelInitializer(func(channel simple.Channel) error {
        channel.Pipeline().AddLast(
            &LengthFieldDecoder{},   // 拆包
            &BizHandler{},           // 业务逻辑
            &Encoder{},              // 编码
        )
        return nil
    }),
)

// 2. 创建客户端
client, _ := agonet.NewClient(handler, agonet.DefaultClientConfig())
client.Start()
defer client.Stop()

// 3. 建立持久连接
conn, _ := client.Dial("tcp", "server:9000")
// conn 保持打开，可反复读写，数据流经 Pipeline
```

### 客户端 YAML 配置

```yaml
config:
  engine:
    multicore: true
  security:
    cliType: tls         # 客户端独立 TLS 类型（可选，默认复用服务端）
    tls:
      caPath: ca.crt
      authCertPath: client.crt
      authKeyPath: client.key
```

### 数据流

```
Client.Dial("tcp", addr)
    │
    ├── TLSType 选择协议（None / TLS / TLCP）
    ├── net.Dial / tls.Dial / tlcp.Dial
    ├── leastConnectionsLoadBalancer 选择 EventLoop
    └── EnrollContext(net.Conn, ctx)
        ├── newStreamConn() → Conn
        ├── EventLoop 接管连接
        └── 返回 Conn

    保持打开，多次 OnTraffic
         ↓
    SimpleEventHandler.OnTraffic → Pipeline.FireChannelRead(reader)
        → LengthFieldDecoder.HandleRead → 解码成完整帧
        → BizHandler.HandleRead → 业务处理
        → ctx.Write(response) → Encoder.HandleWrite → head → TCP 发送
```

### 从连接获取 Channel

```go
import "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet/simple"

channel, err := simple.ChannelFromConn(conn)
// 之后可以操作 Pipeline
channel.Write(request)                         // 写入请求
channel.Close()                                // 关闭连接
```

### 示例

```go
import (
    "encoding/binary"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet/simple"
)

type echoHandler struct{}

func (h *echoHandler) HandleRead(ctx simple.InboundContext, msg any) {
    // msg 已经是解码后的完整帧（非半包）
    ctx.Write(msg)  // 回写
}

handler, _ := simple.NewSimpleEventHandlerWithOptions(
    simple.WithChannelInitializer(func(ch simple.Channel) error {
        ch.Pipeline().AddLast(
            simple.NewLengthFieldDecoder(binary.BigEndian, 1024, 0, 4, 0, 4),
            &echoHandler{},
        )
        return nil
    }),
)

client, _ := agonet.NewClient(handler, agonet.DefaultClientConfig())
client.Start()
defer client.Stop()

conn, _ := client.Dial("tcp", "server:9000")
for i := 0; i < 1000; i++ {
    conn.Write(payload)  // 管道流经编码器后发送
}
conn.Close()
```

## 二、短连接

### SimpleShortClient

`SimpleShortClient` 封装了「建连 → 发 → 收 → 断连」模式。每次 `RequestSync()` 创建一条新连接，请求完成后关闭。

```go
import (
    "context"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet/simple"
)

// simple/short_client.go:15-24
type SimpleShortClient interface {
    // 同步调用：建立连接→发送请求→接收响应→关闭连接
    RequestSync(ctx context.Context, addr string, request any) (any, error)
    // 异步调用：建立连接→发送请求→通过回调处理响应
    RequestAsync(ctx context.Context, addr string, request any, callback ResponseCallback) error
    // 关闭客户端，释放资源
    Close() error
}
```

### Promise 机制

每次调用内部创建一个 Promise，动态注入到 Pipeline 中等待响应：

```
RequestSync(ctx, addr, request)
    │
    ├── client.DialContext("tcp", addr, ctx)   ← 每次都建新连接
    │
    ├── ChannelFromConn(tcon)
    │     ├── AddLast(PromiseInboundHandler)    ← 拦截响应
    │     └── AddLast(InactiveHandler)          ← 连接关闭时 Reject
    │
    ├── channel.Write(request)
    │
    ├── promise.AwaitTimeout(timeout)
    │        ├── 响应到达 → Promise.Resolve(msg)
    │        ├── 超时 → Promise.Reject
    │        └── 连接关闭 → Promise.Reject
    │
    └── defer tcon.Close()
```

### 创建

```go
import (
    "time"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet/simple"
)

// 手动创建
longClient, _ := agonet.NewClient(handler, agonet.DefaultClientConfig())
longClient.Start()

shortClient, _ := simple.NewSimpleShortClient(longClient,
    simple.WithShortClientTimeout(5*time.Second),
)

// 或通过 FX 注入
// fx.Provide(simple.NewShortClientFx)
```

### 使用

```go
import "context"

resp, err := shortClient.RequestSync(context.Background(), "server:9000", requestData)
if err != nil {
    return err
}
// resp 为 any，实际类型取决于 PromiseInboundHandler 捕获的消息
```

`RequestSync` 的签名包含 `addr` 参数——每次调用可以连向不同地址。

## 三、纯 agonet.Client（不使用 Simple）

不使用 Simple 封装，直接实现 `agonet.EventHandler` 接口。**仅适用于**：
- 不需要编解码处理
- 极简协议（如固定长度消息）
- 对 Pipeline 链式模型无需求

```go
import "gitlab.allinfinance.com/aifgo/ag-core/contribute/agonet"

type rawHandler struct{}

func (h *rawHandler) OnTraffic(c agonet.Conn) (action agonet.Action) {
    buf, _ := c.Next(c.InboundBuffered())
    // 手动处理半包/粘包 ...
    return agonet.None
}

func (h *rawHandler) OnOpen(c agonet.Conn) (out []byte, action agonet.Action) {
    return nil, agonet.None
}

func (h *rawHandler) OnClose(c agonet.Conn, err error) (action agonet.Action) {
    return agonet.None
}

// 或嵌入 BuiltinEventEngine 省去空实现
type rawHandler2 struct {
    agonet.BuiltinEventEngine
}
```

**不推荐**，因为失去了 Simple 提供的所有能力（编解码、链式组织、异常传播）。

## 选择建议

| 场景 | 推荐 | 原因 |
|------|------|------|
| 高频 RPC、实时推送 | Simple 长连接 | 连接复用 + Pipeline 链式处理 + 编解码 |
| 低频管理命令 | Simple 短连接 | 用完即关，资源管理简单 |
| 健康检查、探活 | Simple 短连接 | 轻量，发完即走 |
| 固定长度协议、无粘包处理需求 | 纯 Client | 不需要 Simple 的功能性 |
| 需要编解码器 | Simple（长/短均可） | LengthField 等自动处理半包 |

- **默认使用 Simple 长连接**，`ChannelFromConn` 获取 Pipeline
- **短连接**适合管理面操作，频率低于每分钟一次时可考虑
- 短连接内部仍使用 `agonet.Client.Dial`，共享 EventLoop 池
- 短连接超时不宜过长（默认 30s），避免超时请求耗尽资源

## 陷阱与注意事项

### ❌ 短连接不要频繁调用

`RequestSync` 每次建连+拆连，高频场景（>10 QPS）会导致大量 TIME_WAIT。高频通信用长连接 + `ChannelFromConn(ch)` 复用。

### ❌ 短连接超时设置不当

默认 30s，如果后端响应慢且并发高，大量等待请求会占满连接。按实际 SLA 设置，建议 ≤ 10s。

### ❌ 客户端使用 SimpleEventHandler 但不加编解码器

客户端收到的也是裸 TCP 字节流。必须加 `LengthFieldDecoder`（或其他解码器），否则 `HandleRead` 收到的是 `agonet.Reader` 而非解析后的帧。

### ✅ 短连接复用底层 Client

`SimpleShortClient` 包装 `agonet.Client`，不要为每个短连接请求单独创建 Client——Client 内部的 EventLoop 池是共享资源。
