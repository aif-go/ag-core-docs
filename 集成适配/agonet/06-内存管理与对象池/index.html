    内存管理与对象池¶

    路径：pkg/pool/ + pkg/buffer/ | 贯穿整个数据路径的多层内存复用

    架构概览¶

    数据到达 (TCP Read)
    │
    ▼
Goroutine 池  ──  读取线程（ants Worker）
    │
    ▼
bytebufferpool.Get() ── packTCPConn(buffer)
    │                              │
    ▼                              ▼
EventLoop.ch                bytebufferpool.Put()
    │                         （归还临时缓冲区）
    ▼
unpackTCPConn → conn.buffer (ByteBuffer)
    │
    ▼
EventHandler.OnTraffic(c)
    │
    ├── c.Next(n) → byteslice.Get(n)  临时切片
    ├── c.Peek(n) → byteslice.Get(n)  临时切片
    └── c.Discard → byteslice.Put()   归还切片
    │
    ▼
c.inboundBuffer.Write(...)  ← elastic.RingBuffer
    │                           （持久化未处理数据）
    ▼                       ringbuffer.Pool.Get/Put

    1. 字节切片池 — byteslice.Pool¶

    // byteslice.go:29-31
type Pool struct {
    pools [32]sync.Pool  // 32 级，对应 2^0 ~ 2^32
}

    设计：32 个 sync.Pool，每个管理一个 size 区间（2^n）：

    索引 Cap 区间 示例
    0 1 B —
    1 2 B —
    ... ...
    10 1 KB 小消息体
    20 1 MB 大数据帧
    31 2 GB 最大值

    Get：根据申请的 size 定位索引 → 从对应 sync.Pool 取 *byte 指针 → 用 unsafe.Slice 构建切片 

    // byteslice.go:44-57
func (p *Pool) Get(size int) []byte {
    idx := index(uint32(size))
    ptr, _ := p.pools[idx].Get().(*byte)
    if ptr == nil {
        return make([]byte, size, 1<<idx)  // 池空则新建
    }
    return unsafe.Slice(ptr, 1<<idx)[:size]
}

    Put：根据 cap(buf) 定位索引 → 存入 unsafe.SliceData(buf)（存入底层数组指针避逸栈） 

    // byteslice.go:60-72
func (p *Pool) Put(buf []byte) {
    idx := index(uint32(cap(buf)))
    if cap(buf) != 1<<idx { idx-- }  // 非标准大小放前一级
    p.pools[idx].Put(unsafe.SliceData(buf))
}

    关键点： - 只存底层数组的指针（*byte），不存切片 header，避免栈逃逸 - unsafe.SliceData 返回切片底层数组的起始指针 - 非池分配的切片通过减一级索引放入相邻池，尽可能复用

    2. ByteBuffer 池 — bytebufferpool¶

    来自 valyala/bytebufferpool。在 connection.go 中用于两个场景：

    packTCPConn — 数据入队¶

    // connection.go:62-71
func packTCPConn(c *conn, buf []byte) *tcpConn {
    b := bytebufferpool.Get()
    _, _ = b.Write(buf)
    return &tcpConn{c: c, b: b}
}

    Goroutine 从 TCP 读取到栈上 64KB buffer → 写入 ByteBuffer → 通过 EventLoop channel 发送。

    unpackTCPConn — 数据取出¶

    // connection.go:73-86
func unpackTCPConn(tc *tcpConn) *conn {
    _, _ = tc.c.buffer.Write(tc.b.B)  // ByteBuffer → conn.buffer
    bytebufferpool.Put(tc.b)          // 归还 ByteBuffer
    return tc.c
}

    EventLoop 取出 ByteBuffer 中的数据写入 conn.buffer，立即归还 ByteBuffer。

    3. 弹性环形缓冲区 — elastic.RingBuffer¶

    // elastic/elastic_ring_buffer.go:26-28
type RingBuffer struct {
    rb *ring.Buffer  // 懒初始化，首次使用时从池获取
}

    包装 ring.Buffer，增加懒初始化 + 自动归还能力：

    func (b *RingBuffer) instance() *ring.Buffer {
    if b.rb == nil {
        b.rb = rbPool.Get()  // 从 ringbuffer.Pool 取
    }
    return b.rb
}

func (b *RingBuffer) Done() {
    if b.rb != nil {
        rbPool.Put(b.rb)    // 归还到池
        b.rb = nil
    }
}

    inboundBuffer 使用弹性环形缓冲区持久化 EventHandler 未消费的入站数据：

    // event_loop.go:108
_, err := c.inboundBuffer.Write(c.buffer.B)  // OnTraffic 后未读数据写入 inbound
c.buffer.Reset()                              // 清空临时缓冲区

    4. 环形缓冲区池 — ringbuffer.Pool¶

    // ringbuffer.go:49-57
type Pool struct {
    calls       [steps]uint64        // 20 级调用计数
    calibrating uint64               // 是否正在校准
    defaultSize uint64               // 默认初始大小
    maxSize     uint64               // 最大缓存大小
    pool        sync.Pool
}

    自适应校准（P99 优化）¶

    // ringbuffer.go:103-140
func (p *Pool) calibrate() {
    // 1. 读取 20 级的调用计数并排序
    // 2. 取 P95 分位大小作为 defaultSize
    // 3. 取 P95 分位内的最大 size 作为 maxSize
    // 4. 超过 maxSize 的缓冲区不回收（防止内存浪费）
}

    每 42000 次 Put() 触发一次校准，使用原子 CAS 防并发。

    // ringbuffer.go:89-101
func (p *Pool) Put(b *RingBuffer) {
    idx := index(b.Len())
    if atomic.AddUint64(&p.calls[idx], 1) > calibrateCallsThreshold {
        p.calibrate()
    }
    if maxSize == 0 || b.Cap() <= maxSize {
        b.Reset()
        p.pool.Put(b)  // 只有不超过 maxSize 时才回池
    }
}

    关键点： - 校准频率：约 42000 次 Put 触发一次 - 默认大小：P95 分位最常见的大小 - 超过 maxSize 的缓冲区直接丢弃（防止大对象常驻内存池）

    index 计算¶

    // ringbuffer.go:161-172
func index(n int) int {
    n--
    n >>= minBitSize  // minBitSize = 6，即 64 字节为最小单位
    return min(bits.Len(uint(n)), steps-1)
}

    按 2^(6+index) 分级，最小 64B，最大 64B * 2^19 ≈ 33MB，共 20 级。

    5. Goroutine 池 — goroutine.DefaultWorkerPool¶

    // goroutine.go:34-44
func Default() *Pool {
    return ants.NewPool(DefaultAntsPoolSize, ants.WithOptions(ants.Options{
        ExpiryDuration: 10 * time.Second,
        Nonblocking:    true,
        PanicHandler:   func(a any) { slog.Error("goroutine pool panic", "err", a) },
    }))
}

    参数： - 容量：256K（1 << 18） - 非阻塞（Nonblocking）：池满时不阻塞调用方 - 过期清理：10 秒 - 全局单例：goroutine.DefaultWorkerPool

    用途： 

    // 1. TCP 读取 goroutine（listenStream / client.EnrollContext）
goroutine.DefaultWorkerPool.Submit(func() {
    for {
        n, err := tc.Read(buffer[:])
        el.ch <- packTCPConn(c, buffer[:n])
    }
})

// 2. 异步写入（AsyncWrite / Wake / Close）
goroutine.DefaultWorkerPool.Submit(func() {
    c.loop.ch <- fn
})

// 3. EventLoop Execute 异步任务
func (el *eventloop) Execute(ctx context.Context, runnable Runnable) error {
    return goroutine.DefaultWorkerPool.Submit(func() {
        el.ch <- func() error { return runnable.Run(ctx) }
    })
}

    6. 环形缓冲区原始实现 — ring.Buffer¶

    位于 pkg/buffer/ring/，实现一个通用的环形缓冲区：

    • New(size int) *Buffer — 创建指定大小的环形缓冲区
    • Write(p []byte) (n int, err error) — 写入数据，自动扩容
    • Read(p []byte) (n int, err error) — 读取数据
    • Peek(n int) (head []byte, tail []byte) — 窥视不移动读指针（可能返回两段）
    • Discard(n int) (int, error) — 丢弃 n 字节
    • IsEmpty() bool / Buffered() int / Len() int — 状态查询
    • Reset() / CloseWithError(err) — 重置/关闭

    内存流全景¶

    TCP Read Buffer (64KB 栈上)
    │
    ▼ packTCPConn
bytebufferpool.ByteBuffer ──────────► EventLoop.ch
    │                                      │
    │                                 unpackTCPConn
    ▼                                      │
conn.buffer (ByteBuffer) ◄─────────────────┘
    │
    │ OnTraffic(c)
    │ c.Read / c.Next / c.Peek → byteslice.Get(n)
    │ c.Discard → byteslice.Put(buf)
    │
    ▼ 未消费数据
conn.inboundBuffer (elastic.RingBuffer)
    │
    │ 下次 OnTraffic → c.inboundBuffer.IsEmpty() → false
    │ → 先读 inboundBuffer，再读 conn.buffer
    ▼
    conn.release() → inboundBuffer.Done() → ringbuffer.Pool.Put(rb)
                     bytebufferpool.Put(conn.buffer)
                     byteslice.Put(cache)
