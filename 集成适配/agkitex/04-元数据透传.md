# 元数据透传

> 路径：`metadata/http2.go` | Kitex HTTP2 StreamingMetaHandler

## 概述

元数据透传通过 Kitex 的 `remote.StreamingMetaHandler` 接口实现，在 HTTP2 流式请求的 header 中传递 `agmetadata` 中的键值对，实现 RPC 调用链的上下文透传。

```
Client                         Server
  │                              │
  ├── OnConnectStream            │
  │   ├── 读取 context MD        │
  │   ├── AppendToOutgoingCtx    │
  │   └── HTTP2 header 发送 ────►│
  │                              ├── OnReadStream
  │                              │   ├── FromIncomingContext
  │                              │   ├── ParseMdToContext
  │                              │   └── 注入 context
  │                              │
  │ ◄──────── HTTP2 header ──────┤
```

## 实现

### 客户端 StreamingMetaHandler

```go
// http2.go:36-55
func (*agKitexClientAgMetadataHTTP2Handler) OnConnectStream(ctx context.Context) (context.Context, error) {
    ri := rpcinfo.GetRPCInfo(ctx)
    if !isGRPC(ri) {
        return ctx, nil  // 非 gRPC 协议跳过
    }

    var kmd []string
    err := agmetadata.HandlerMdFromContext(ctx, func(k, v string) {
        kmd = append(kmd, k, v)  // 收集 key, value, key, value...
    })

    if len(kmd) > 0 {
        rctx = metadata.AppendToOutgoingContext(ctx, kmd...)
    }
    return rctx, nil
}
```

**流程**：
1. 检查当前 RPC 是否为 gRPC 协议
2. 从 context 中通过 `agmetadata.HandlerMdFromContext` 读取 MD
3. 将 MD 追加到 HTTP2 的 outgoing context 中

### 服务端 StreamingMetaHandler

```go
// http2.go:82-109
func (*agKitexServerAgMetadataHTTP2Handler) OnReadStream(ctx context.Context) (context.Context, error) {
    ri := rpcinfo.GetRPCInfo(ctx)
    if !isGRPC(ri) {
        return ctx, nil
    }

    md, ok := metadata.FromIncomingContext(ctx)  // 读取 HTTP2 header
    rctx, err := agmetadata.ParseMdToContext(ctx, func(key string) ([]string, bool) {
        tmp := md.Get(key)
        if len(tmp) >= 1 {
            return []string{tmp[0]}, true  // 多值取第一个
        }
        return nil, false
    })
    return rctx, nil
}
```

**流程**：
1. 检查是否为 gRPC 协议
2. 从 HTTP2 的 incoming context 中读取 metadata
3. 通过 `agmetadata.ParseMdToContext` 将 header 值写入 context

## 注册

通过 FX 提供函数，注册为 Kitex 的 MetaHandler：

```go
// http2.go:115-123
func NewAgKitexClientAgMetadataHTTP2HandlerOption() *client.Option {
    opt := client.WithMetaHandler(AgKitexClientAgMetadataHTTP2Handler)
    return &opt
}

func NewAgKitexServerAgMetadataHTTP2HandlerOption() *server.Option {
    opt := server.WithMetaHandler(AgKitexServerAgMetadataHTTP2Handler)
    return &opt
}
```

## 与 aghertz 的对比

| 维度 | aghertz (HTTP) | agkitex (RPC/gRPC) |
|------|---------------|-------------------|
| **接口** | `app.HandlerFunc` | `remote.StreamingMetaHandler` |
| **触发点** | 每个请求的中间件 | 流建立时 OnConnectStream / OnReadStream |
| **传输** | HTTP header（Request.Header） | HTTP2 metadata |
| **协议判断** | 无（纯 HTTP） | 仅 gRPC 协议时生效 |
| **适配器工厂** | `NewAgHertzClientAgMetadataMiddleware()` | `NewAgKitexClientAgMetadataHTTP2HandlerOption()` |
