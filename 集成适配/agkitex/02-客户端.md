# 客户端

> 路径：`client/`

AgKitex 客户端基于 Kitex `client.Suite`，采用 **KitexSuiteBuilder** 模式统一组装配置、传输协议、服务发现、负载均衡和中间件。

## 文件列表

| 文件 | 职责 |
|------|------|
| `client.go` | KitexSuiteBuilder + 构建 Suite |
| `config.go` | KitexClientConfig + 默认值 |
| `middleware.go` | PrioritizedClientMiddleware + 排序 |
| `resolver.go` | BuildKitexResolver（双模式：agnacos / nacos） |
| `ag_nacos_resolver.go` | 自定义 AgNacosResolver（Spring gRPC 兼容） |
| `zfx_kitex_client.go` | FX Module |

### BuildSuite

```go

```

构建流程：

```
BuildSuite()
    │
    ├── 1. 自定义选项 (ClientOptions)
    │
    ├── 2. 传输协议
    │       ├── "grpc" → WithTransportProtocol(transport.GRPC)
    │       ├── "grpcstream" → WithTransportProtocol(transport.GRPCStreaming)
    │       └── 默认 → GRPC
    │
    ├── 3. 服务发现 (Resolver != nil → WithResolver)
    │
    ├── 4. 负载均衡 (LoadBalancer != nil → WithLoadBalancer)
    │
    ├── 5. RPC 超时 (RpcTimeout > 0 → WithRPCTimeout)
    │
    ├── 6. 中间件
    │       ├── 优先中间件复制
    │       ├── 普通中间件 → Normal 优先级
    │       ├── 排序
    │       └── 每个 → client.WithMiddleware()
    │
    ├── 7. gRPC 连接池 (GRPCConnPoolSize > 0 → WithGRPCConnPoolSize)
    │
    └── 8. 组装 KitexClientSuite
```

## 2. 配置 (`config.go`)

```go
// config.go:16-28
type KitexClientConfig struct {
    RpcTimeout    time.Duration  // RPC 超时（秒），默认 30s
    TransportType string         // 传输协议，默认 "grpc"
    Resolver      ResolverConfig // 服务发现配置
    Conn          ConnConfig     // 连接配置
}

type ResolverConfig struct {
    Enable bool        // 是否启用，默认 true
    Type   string      // "agnacos"（自定义）| "nacos"（官方）
    Nacos  NacosConfig // Group, Cluster
}

type ConnConfig struct {
    GRPCConnPoolSize uint32  // 默认 GOMAXPROCS * 1.5
}
```

配置前缀：`kitex.client`

默认值：
```go
// config.go:67-87
RpcTimeout:          30,
TransportType:       "grpc",
Resolver.Enable:     true,
Resolver.Type:       "agnacos",   // 优先使用自定义 Resolver
Resolver.Nacos:      {Group: "DEFAULT_GROUP", Cluster: "DEFAULT"},
Conn.GRPCConnPoolSize: GOMAXPROCS * 1.5,
```

## 3. 服务发现构建 (`resolver.go`)

支持两种 Resolver 类型：

```go
// resolver.go:12-45
func BuildKitexResolver(config *KitexClientConfig, namingClient naming_client.INamingClient) discovery.Resolver {
    if !config.Resolver.Enable { return nil }
    if namingClient == nil { return nil }

    switch config.Resolver.Type {
    case "agnacos":  // 自定义：兼容 Spring gRPC
        return NewAgNacosResolver(namingClient,
            WithGroup(config.Resolver.Nacos.Group),
            WithCluster(config.Resolver.Nacos.Cluster),
        )
    case "nacos":    // 官方：kitex-contrib/registry-nacos
        return resolver.NewNacosResolver(namingClient,
            resolver.WithGroup(config.Resolver.Nacos.Group),
            resolver.WithCluster(config.Resolver.Nacos.Cluster),
        )
    }
}
```

**`agnacos` vs `nacos` 的选择**：
- `agnacos`（自定义）— 解析 Spring gRPC 服务的 `gRPC_port` metadata
- `nacos`（官方）— 标准 Kitex 服务解析

## 5. RPC 调用示例

```go
// 注入 KitexClientSuite，创建生成的 RPC Client
type MyService struct {
    cli myservice.Client  // 由 protobuf 生成的 Kitex Client
}

func NewMyService(suite *client.KitexClientSuite) *MyService {
    cli := myservice.NewClient("my-service", client.WithSuite(suite))
    return &MyService{cli: cli}
}

// 发起 RPC 调用
func (s *MyService) GetUser(ctx context.Context, req *UserRequest) (*UserResponse, error) {
    return s.cli.GetUser(ctx, req)
}
```

实际使用时，通过 FX 注入 `*client.KitexClientSuite` 到生成的 RPC Client 构造函数。
