    服务端¶

    路径：server/

    AgKitex 服务端基于 Kitex 的 server.Server，采用 KitexServerSuiteBuilder 模式统一组装配置、中间件和服务注册，并通过 AgKitexServiceRegistryHolder 管理多个服务的注册。

    文件列表¶

    文件 职责
    server.go KitexServerSuiteBuilder + AgKitexServer + 配置构建
    config.go KitexServerProperties + 自适应端口
    middleware.go PrioritizedServerMiddleware + 排序
    service_registry.go AgKitexServiceRegistry + Holder
    zfx_kitex_server.go FX Module
    registry/ 服务注册

    1. AgKitexServer¶

    // server.go:46-48
type AgKitexServer struct {
    KitexServer server.Server
}

    实现 ag_server.Server 接口：

    // server.go:60-77
func (s *AgKitexServer) Start(ctx context.Context) error {
    // 打印服务信息（服务名、方法列表）
    sinfos := s.KitexServer.GetServiceInfos()
    for sname, sinfo := range sinfos {
        slog.Info("Kitex Server Service Info",
            "service_name", sname,
            "method_count", len(sinfo.Methods),
            "method_list", sinfo.Methods,
        )
    }
    return s.KitexServer.Run()
}

// server.go:79-89
func (s *AgKitexServer) Stop(ctx context.Context) error {
    return s.KitexServer.Stop()
}

    通过 FX 被注入为 group:"ag_servers"，由 ag-app 自动管理生命周期。

    2. KitexServerSuiteBuilder¶

    // server.go:28-43
type KitexServerSuiteBuilder struct {
    ServerOptions         []server.Option              // 自定义选项
    Properties            *KitexServerProperties       // 配置
    Registry              registry.Registry            // 服务注册器
    Middlewares           []endpoint.Middleware         // 普通中间件
    PrioritizedMiddlewares []PrioritizedServerMiddleware // 带优先级中间件
}

    BuildServerSuite¶

    // server.go:103-132
func (builder *KitexServerSuiteBuilder) BuildServerSuite() (*KitexServerSuite, error)

    构建流程：

    BuildServerSuite()
    │
    ├── 1. 添加自定义选项 (ServerOptions)
    │
    ├── 2. optionsFromConfig()
    │       ├── findKitexHostPort() → 地址（支持自适应端口）
    │       ├── WithServiceAddr()
    │       ├── WithServerBasicInfo() → 服务名
    │       ├── WithRegistryInfo() → 注册信息（含 gRPC_port 标签）
    │       └── gRPC 配置：WithGRPCKeepaliveParams + 元处理器
    │
    ├── 3. middlewareOptions()
    │       ├── 普通中间件 → 转换为 Normal 优先级
    │       ├── 排序：按优先级值升序
    │       └── 每个中间件 → server.WithMiddleware()
    │
    ├── 4. 如果 Registry != nil → server.WithRegistry()
    │
    └── 5. 组装 KitexServerSuite → server.WithSuite(suite)

    3. 配置 (config.go)¶

    // config.go:18-27
type KitexServerProperties struct {
    Host          string  // 绑定 Host，默认 "0.0.0.0"
    Port          int     // 绑定端口，默认 7000
    AdaptivePort  bool    // 自适应端口
    ServiceName   string  // 服务名，默认 "kitex-server"
    EnableIPRange string  // IP 范围

    Grpc Grpc
}

type Grpc struct {
    Enable            bool  // 默认 true（gRPC 协议）
    MaxConnectionIdle int   // 最大空闲连接时间（秒）
}

    默认 gRPC 协议开启，通过 server.WithMetaHandler(transmeta.ServerHTTP2Handler) 启用 HTTP2 元处理器。

    自适应端口逻辑与 aghertz 一致：调用 ip.IsHostAvailable() + ip.GetAvailablePort()。

    注册信息构建（optionsFromConfig 行 164-188）： 

    regInfo := &kregistry.Info{
    Tags: map[string]string{},
}
regInfo.Weight = 1    // 兼容 grpc-spring 项目（默认权重 1 vs Kitex 默认 10）
regInfo.Tags["gRPC_port"] = fmt.Sprintf("%d", port)  // 兼容 Spring gRPC 服务发现
if kconf.EnableIPRange != "" {
    regInfo.SkipListenAddr = true  // 使用 IP Range 覆盖注册地址
}

    5. 服务注册 (service_registry.go)¶

    AgKitexServiceRegistry¶

    // service_registry.go:21-26
type AgKitexServiceRegistry struct {
    ServiceInfo *serviceinfo.ServiceInfo  // Kitex 生成的 ServiceInfo
    Handler     interface{}               // 业务 Handler
    Opts        []server.RegisterOption   // 注册选项
}

// service_registry.go:69-78
func (r *AgKitexServiceRegistry) Register(svr server.Server, options ...server.RegisterOption) error {
    if r.ServiceInfo == nil { return ErrServiceInfoIsNil }
    if r.Handler == nil { return ErrHandlerIsNil }
    return svr.RegisterService(r.ServiceInfo, r.Handler, append(r.Opts, options...)...)
}

    AgKitexServiceRegistryHolder¶

    // service_registry.go:29-32
type AgKitexServiceRegistryHolder struct {
    Registries []*AgKitexServiceRegistry
}

// service_registry.go:81-89
func (h *AgKitexServiceRegistryHolder) RegisterService(svr server.Server, ...) error {
    for _, reg := range h.Registries {
        if err := reg.Register(svr, options...); err != nil {
            return err
        }
    }
    return nil
}

    通过 FX 的 group:"ag_kitex_service_registry" 聚合多个服务，在 fx.Invoke 中统一注册到 Kitex Server。

    6. 启动流程¶

    FX 启动
    │
    ├── NewKitexServerProperties → *KitexServerProperties
    ├── FxNewKitexServerSuiteBuilder
    │     └── 聚合: ServerOptions + Config + Registry + Middlewares
    │
    ├── FxBuilderKitexServerSuite → *KitexServerSuite
    │     └── builder.BuildServerSuite()
    │
    ├── NewKitexServerWithSuite → server.Server
    │
    ├── FxNewKitexServiceRegistryHolder
    │     └── 聚合: group:"ag_kitex_service_registry" 的所有服务
    │
    ├── fx.Invoke → holder.RegisterService(kitexServer)
    │     └── 注册 Protobuf 定义的所有 RPC Service
    │
    └── NewAgKitexServer → group:"ag_servers"
          └── ag-app.Run() → AgKitexServer.Start() → server.Run()
