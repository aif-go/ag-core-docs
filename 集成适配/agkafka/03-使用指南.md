## 快速开始

### 1. 添加依赖

```go
require (
    gitlab.allinfinance.com/aifgo/ag-core latest
    github.com/IBM/sarama latest
)
```

### 2. 注册 FX 模块

```go
import (
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agsarama"
)

func main() {
    app := fxs.FxAppMode(
        fxs.FxAgConfModule,
        agsarama.FxAgsaramaModule,
    )
    app.Run()
}
```

### 3. 注入客户端

```go
type MyService struct {
    kafka sarama.Client
}

func NewMyService(result agsarama.FxResult) *MyService {
    // 直接获得可用的 sarama.Client
    return &MyService{kafka: result.Client}
}
```

## 配置

### 最小配置

```yaml
agsarama:
  brokers:
    - 127.0.0.1:9092
```

### 完整配置示例

```yaml
agsarama:
  brokers:
    - kafka-1:9092
    - kafka-2:9092
    - kafka-3:9092

  clientID: my-app                    # 客户端 ID，用于监控
  channelBufferSize: 256              # 通道缓冲区大小
  apiVersionsRequest: true            # 发送 ApiVersions 请求
  version: 2.8.0                      # Kafka 版本

  # ====== Admin ======
  admin:
    retry:
      max: 5
      backoff: 100                    # ms
    timeout: 3000                     # ms

  # ====== 网络 ======
  net:
    maxOpenRequests: 5
    dialTimeout: 30000                # ms
    readTimeout: 30000
    writeTimeout: 30000
    keepAlive: 0

    # SASL 认证（按需启用）
    # sasl:
    #   enable: true
    #   mechanism: plain               # plain | scram-sha-256 | scram-sha-512
    #   user: myuser
    #   password: mypass

  # ====== 元数据 ======
  metadata:
    retry:
      max: 3
      backoff: 250
    refreshFrequency: 600000          # ms, 10分钟
    full: true
    allowAutoTopicCreation: true

  # ====== 生产者 ======
  producer:
    maxMessageBytes: 1048576          # 1MB
    requiredAcks: wait_for_local       # no_response | wait_for_local | wait_for_all
    timeout: 10000                    # ms
    compression: none                 # none | gzip | snappy | lz4 | zstd
    partitioner: hash

    return:
      successes: false                # 是否返回成功确认
      errors: true                    # 是否返回错误

    retry:
      max: 3
      backoff: 100

    # 幂等生产者（按需启用）
    # idempotent: true

  # ====== 消费者 ======
  consumer:
    group:
      session:
        timeout: 10000                # ms
      heartbeat:
        interval: 3000
      rebalance:
        timeout: 60000
        retry:
          max: 4
          backoff: 2000

    retry:
      backoff: 2000
    maxWaitTime: 500                  # ms
    maxProcessingTime: 100            # ms

    offsets:
      autoCommit:
        enable: true
        interval: 1000                # ms
      initial: -1                     # -1=OffsetNewest, -2=OffsetOldest
      retry:
        max: 3

    isolationLevel: read_uncommitted   # read_uncommitted | read_committed
```

## 生产者开发

```go
type OrderService struct {
    kafka sarama.Client
}

// 注入客户端
func NewOrderService(result agsarama.FxResult) *OrderService {
    return &OrderService{kafka: result.Client}
}

// 发送消息
func (s *OrderService) PublishOrder(ctx context.Context, order *Order) error {
    producer, err := sarama.NewAsyncProducerFromClient(s.kafka)
    if err != nil {
        return err
    }
    defer producer.Close()

    msg := &sarama.ProducerMessage{
        Topic: "orders",
        Key:   sarama.StringEncoder(order.ID),
        Value: sarama.ByteEncoder(orderJSON),
    }

    producer.Input() <- msg

    select {
    case success := <-producer.Successes():
        slog.Info("produced", "partition", success.Partition, "offset", success.Offset)
        return nil
    case err := <-producer.Errors():
        return err.Err
    case <-ctx.Done():
        return ctx.Err()
    }
}
```

### 同步生产者

```go
func (s *OrderService) PublishSync(ctx context.Context, topic string, value []byte) error {
    producer, err := sarama.NewSyncProducerFromClient(s.kafka)
    if err != nil {
        return err
    }
    defer producer.Close()

    partition, offset, err := producer.SendMessage(&sarama.ProducerMessage{
        Topic: topic,
        Value: sarama.ByteEncoder(value),
    })
    slog.Info("produced", "partition", partition, "offset", offset)
    return err
}
```

## 消费者开发

```go
type OrderConsumer struct {
    kafka sarama.Client
}

func NewOrderConsumer(result agsarama.FxResult) *OrderConsumer {
    return &OrderConsumer{kafka: result.Client}
}

func (c *OrderConsumer) Start(ctx context.Context) error {
    group, err := sarama.NewConsumerGroupFromClient("order-group", c.kafka)
    if err != nil {
        return err
    }
    defer group.Close()

    handler := &OrderHandler{}

    for {
        err := group.Consume(ctx, []string{"orders"}, handler)
        if err != nil {
            return err
        }
        if ctx.Err() != nil {
            return ctx.Err()
        }
    }
}

// 消费者 Handler
type OrderHandler struct{}

func (h *OrderHandler) Setup(session sarama.ConsumerGroupSession) error {
    slog.Info("consumer setup", "memberID", session.MemberID())
    return nil
}

func (h *OrderHandler) Cleanup(session sarama.ConsumerGroupSession) error {
    return nil
}

func (h *OrderHandler) ConsumeClaim(session sarama.ConsumerGroupSession, claim sarama.ConsumerGroupClaim) error {
    for msg := range claim.Messages() {
        slog.Info("consumed",
            "topic", msg.Topic,
            "partition", msg.Partition,
            "offset", msg.Offset,
            "value", string(msg.Value),
        )
        session.MarkMessage(msg, "")  // 确认消费
    }
    return nil
}
```

## 最佳实践

### ✅ 通过 FX 模块注入 Client

总是通过 `agsarama.FxAgsaramaModule` 创建和管理 `sarama.Client`，它自动处理配置绑定和生命周期。

### ✅ 使用 AsyncProducer 应对高吞吐

同步生产者（SendMessage）每次调用都会等待确认，吞吐受限。高吞吐场景使用 `AsyncProducer` + `Successes()`/`Errors()` 通道。

### ✅ 合理配置 Consumer 超时

```yaml
consumer:
  group:
    session:
      timeout: 10000       # 会话超时，建议 10s
    heartbeat:
      interval: 3000        # 心跳间隔，建议 session.timeout / 3
    rebalance:
      timeout: 60000        # 重平衡超时
```

### ✅ 幂等生产者防重复

```yaml
producer:
  idempotent: true          # 启用幂等，防止网络重试导致的消息重复
```

### ❌ 不要在 consumer 中做耗时操作

```go
// ❌ 这样会导致 rebalance 超时
func (h *Handler) ConsumeClaim(session, claim) error {
    for msg := range claim.Messages() {
        processSlowly(msg)    // 耗时操作
        session.MarkMessage(msg, "")
    }
}

// ✅ 异步处理
func (h *Handler) ConsumeClaim(session, claim) error {
    for msg := range claim.Messages() {
        go processAsync(msg)  // 异步处理
        session.MarkMessage(msg, "")
    }
}
```

### ❌ 不要忘记 MarkMessage

不调用 `MarkMessage` 会导致消费者重启时重新消费旧消息。

## FAQ

**Q: 包名为什么是 `agsarama` 而不是 `agkafka`？**
A: Sarama 是 Go 语言最主流的 Kafka 客户端库，包名直接反映底层依赖。

**Q: 如何配置 SASL 认证？**
A:
```yaml
agsarama:
  net:
    sasl:
      enable: true
      mechanism: plain
      user: myuser
      password: mypass
```

**Q: 如何查看当前 Kafka 版本对应的 Sarama Version？**
A: 使用 `sarama.ParseKafkaVersion("2.8.0")` 字符串格式。不配置时使用 Sarama 默认版本。

**Q: 如何配置从最早偏移量开始消费？**
A: 设置 `consumer.offsets.initial: -2`（`-1` = OffsetNewest，`-2` = OffsetOldest）。
