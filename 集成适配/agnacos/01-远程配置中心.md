# 远程配置中心

> 路径：`agnacos/config/` | 从 Nacos 拉取远程配置并注入 ag_conf 配置链

## 配置结构

```go
// config/nacos_properties.go:11-26
type NacosConfigProperties struct {
    Enable  bool
    common.SCProperties             // 连接信息：ServerAddr/NameSpace/UserName/Password
    DataIDs []DataIDInfo
}

type DataIDInfo struct {
    DataID      string   // required — 配置 ID
    Group       string   // 默认 DEFAULT_GROUP
    Type        string   // 默认 yaml — 支持 yaml/properties/json 等 reader
    AutoRefresh bool     // 默认 true — 是否监听变更
}
```

**配置前缀**：`nacos.config`

```yaml
nacos:
  config:
    enable: true
    serveraddr: 192.168.1.1:8848
    namespace: aic-dev
    username: nacos
    password: nacos
    dataids:                              # ← 字段 DataIDs → 扁平化 key 为 dataids
      - dataid: application.yaml
        group: DEFAULT_GROUP
        type: yaml
        autorefresh: true
      - dataid: db-config.yaml
        group: DEFAULT_GROUP
        type: yaml
        autorefresh: true
```

> ⚠️ **字段名对应关系**：binder 使用 Go 字段名 `DataIDs` 构建查找 key。由于 ag_conf 的 `getPropertyFold` 使用 `EqualFold` 做**大小写不敏感**匹配，YAML 中写 `dataids`（全小写）可以正确绑定。但 key 的名称必须与字段名一致——`dataidlist` 这种与 `DataIDs` 拼写不同的 key **绑定不到值**。

### 键名对应关系

| YAML 键 | 对应字段 | 是否绑定成功 |
|---------|---------|------------|
| `dataids` | `DataIDs` | ✅ 大小写不敏感匹配 |
| `dataids[0].dataid` | `DataIDs[0].DataID` | ✅ |
| `dataidlist` | 无对应字段 | ❌ 拼写不匹配 |

## 客户端创建

```go
// config/config.go:23-57
func NewNacosConfigClient(p *NacosConfigProperties) (config_client.IConfigClient, error)
```

- 如果 `p == nil || !p.Enable`，返回 `nil, nil`（静默跳过，不阻断启动）
- 调用 `common.BuildServerConfig` / `BuildClientConfig` 构建 SDK 参数
- 通过 `clients.NewConfigClient()` 创建 SDK 的 IConfigClient

## 核心流程：远程配置注入

`EnableNacosRemoteConfig` 完成配置拉取到 ag_conf 注入的全流程：

```
EnableNacosRemoteConfig(env, iClient, p)
    │
    ├── 遍历 DataIDs（倒序，保证添加顺序）
    │
    ├── iClient.GetConfig(DataID, Group)            ← 拉取配置原文
    │
    ├── reader.Readers[type](content)               ← 按类型解析为 map
    │   └── ag_ext.GetFlattenedMap()                 ← 展平为扁平 map
    │
    ├── NacosPropertySource → env 的 PropertySources
    │   ├── 已存在 → ReplaceSource
    │   └── 不存在 → AddAfter(SourceKeySystemEnvironment)
    │       └── 优先级：系统环境变量 > Nacos > 本地文件
    │
    ├── ag_conf.CreateOrDecryptPropertySource        ← 密钥解密
    │
    └── registerNacosWatcherIfNeed(info, iClient)
          └── AutoRefresh=true → NacosConfigWatcher
```

### PropertySource 命名

```go
// config/ag_conf_nacos.go:107-109
func getSourceKey(dataidinfo *DataIDInfo) string {
    return fmt.Sprintf("%s-%s_%s", SourceKeyNacosPrefix, dataidinfo.Group, dataidinfo.DataID)
}
```

命名格式：`[NACOS]-{Group}_{DataID}`，例如 `[NACOS]-DEFAULT_GROUP_application.yaml`。该 key 用于在 PropertySources 链中查找和替换。

### 优先级

Nacos 配置的优先级为：**系统环境变量 > Nacos 远程配置**（`AddAfter(SourceKeySystemEnvironment)`）。这意味着本地环境变量可以覆盖 Nacos 配置，适合不同环境差异化配置。

### 解密支持

注入完成后调用 `ag_conf.CreateOrUpdateDecryptForPropertySource`，对配置中的加密值进行解密。解密器注册在 ag_conf 模块中，Nacos 配置中加密值格式与本地配置一致（如 `${{cipher}}...`）。

## 配置变更监听

当 `DataIDInfo.AutoRefresh = true`（默认），会注册一个 `NacosConfigWatcher`：

```go
// config/nacos_watcher.go:30-49
func (w *NacosConfigWatcher) Start(ctx context.Context, doChange ChangePropertySources) {
    w.iClient.ListenConfig(vo.ConfigParam{
        DataId: winfo.DataID,
        Group:  winfo.Group,
        OnChange: func(namespace string, group string, dataId string, data string) {
            ps, _ := BuildNacosConfigPropertySource(winfo, data)  // 重新解析
            doChange([]ag_conf.IPropertySource{ps})                // 通知 WatchManager
        },
    })
}
```

### 变更传播路径

```
Nacos 配置变更
    │
    ▼
SDK OnChange 回调
    │
    ├── BuildNacosConfigPropertySource → 重新解析 + 展平
    │
    └── doChange([newPropertySource])
          │
          ▼
    WatchManager.refreshChan
          │
          ▼
    refreshPropertySources()
        ├── PropertySources.ReplaceSource()   ← 替换旧源
        └── 触发 RegChangeListener 的回调      ← 通知订阅者
```

监听器在 `WatchManager.run()` 中统一管理，通过 `ag_conf.RegisterWatcher` 注册，`WatcherManager` 在后台 goroutine 中运行。手动调用 `Stop()` 可取消监听。

## 使用示例

```go
// 手动注册
p, _ := config.NewNacosConfigProperties(binder)
iClient, _ := config.NewNacosConfigClient(p)
config.EnableNacosRemoteConfig(env, iClient, p)

// 或通过 FX 注入（推荐）
fx.Module("app",
    fxNacosConfigMode,
    fxEnableNacosRemoteConfigMode,
)
```

## 注意事项

- **DataIDs 倒序遍历**（`for i := dataidCount - 1; i >= 0`）：保证多个 DataID 按配置顺序添加到 PropertySources 链中
- **空配置忽略**：如果某个 DataID 内容为空，会跳过（`continue`），不会阻断启动
- **配置去重**：`ContainsSource` 检查是否已存在同名 PropertySource，避免重复注册
- **SDK 类型枚举**：Type 字段映射到 `vo.ConfigType`，不指定类型时可能获取不到值（代码注释标注）
- **字段名即配置键**：binder 使用 Go 字段名（`DataIDs`/`DataID`/`Group`/`Type`/`AutoRefresh`）构建扁平 key，大小写不敏感，但名称拼写必须一致
