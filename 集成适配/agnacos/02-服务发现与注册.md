# 服务发现与注册

> 路径：`agnacos/naming/` | 创建 INamingClient，供 agkitex / aghertz 使用

## 概述

`naming/` 负责创建 Nacos SDK 的 `INamingClient`，通过 FX 注入给下游模块。agkitex 和 aghertz 各自用其实现客户端服务发现和服务端注册，详见 [03-服务注册与发现](../agkitex/03-服务注册与发现.md) 和 [03-服务注册与发现](../aghertz/03-服务注册与发现.md)。

## 配置结构

```go
// naming/nacos_properties.go:11-24
type NacosNamingProperties struct {
    Enable bool
    common.SCProperties             // 连接信息：ServerAddr/NameSpace/UserName/Password
}
```

配置前缀：`nacos.naming`

```yaml
nacos:
  naming:
    enable: true
    serveraddr: 192.168.1.1:8848
    namespace: aic-dev
    username: nacos
    password: nacos
```

## 客户端创建

```go
// naming/naming.go:23-55
func NewNacosNamingClient(p *NacosNamingProperties) (naming_client.INamingClient, error)
```

- `p == nil || !p.Enable` → 返回 `nil, nil`（静默跳过）
- `ServerAddr` 为空 → 返回错误 `"nacos server addr is empty"`，阻断启动

## 默认值

`common.DefaultSCProperties()` 默认：

| 字段 | 默认值 |
|------|--------|
| Schema | `http` |
| ContextPath | `/nacos` |
| LogLevel | `error` |

ServerAddr 和 NameSpace 无默认值，必须在 YAML 中配置。

## FX 模块

```go
// zfx_conf_nacos.go:32-38
var FxNacosNamingMode = fx.Module("fx_nacos_naming",
    fx.Provide(
        naming.NewNacosNamingProperties,
        naming.NewNacosNamingClient,
    ),
)
```

## 注意事项

- **静默跳过**：Enable=false 时返回 `nil, nil`，调用方需处理 nil 情况
- **INamingClient 是 SDK 接口**：`naming/` 只负责创建，不封装 SelectInstances 等调用
- **config 和 naming 共用连接**：如果同时使用配置中心和服务发现，`SCProperties` 在两个前缀下各自配置，连接地址应一致
