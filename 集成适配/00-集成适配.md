# 🔌 集成适配层 — contribute/

第三方框架的桥接适配层，位于 `contribute/` 目录。

## 模块一览

| 模块 | 包路径 | 说明 |
|------|--------|------|
| [[agdb/00-Agdb\|agdb (GORM)]] | `contribute/agdb/` | GORM 数据库 ORM 封装 |
| [[agdb/agdao/00-Agdao\|agdao DAO 层]] | `contribute/agdb/agdao/` | 基础 CRUD 抽象 |
| [[aghertz/00-AgHertz\|aghertz (Hertz)]] | `contribute/aghertz/` | 字节跳动 Hertz HTTP 框架适配 |
| [[agkitex/00-AgKitex\|agkitex (Kitex)]] | `contribute/agkitex/` | 字节跳动 Kitex RPC 框架适配 |
| [[agredis/00-AgRedis\|agredis (Redis)]] | `contribute/agredis/` | Redis 客户端封装 |
| [[agkafka/00-AgKafka\|agkafka (Kafka)]] | `contribute/agkafka/` | Kafka 消息队列集成 |
| [[agnacos/00-AgNacos\|agnacos (Nacos)]] | `contribute/agnacos/` | 服务发现 + 配置中心 |
| [[agonet/00-Agonet\|agonet 网络层]] | `contribute/agonet/` | 网络通信抽象 |

## 设计理念

- 每个适配器封装具体中间件的 SDK 细节
- 对外暴露统一接口（如 `Server`、`Client`）
- 通过 `ag_common` 的接口定义解耦
