# FX 集成

> 文件：`zfx_server_hertz.go` + `zfx_client_hertz.go` + `registry/zfx_registy.go` + `discovery/zfx_discovery.go`

## 模块结构

```
FxAgHertzServerModule           ← Server Module (zfx_server_hertz.go)
  ├── registry.FxHertzRegistyModule ← Nacos 注册 (可选)
  │     └── nacos.FxNacosRegistyModule
  ├── NewHertzServerProperties  → *HertzServerProperties
  │
  ├── FxNewHertzServerConfigParam → *HertzServerConfigParam
  ├── BuildHertzServerConfigOption → group:"aghertz_server_config_options"
  ├── FxNewHertsServerConfigSuite  → ConfigSuite (聚合)
  ├── NewHertzServerWithSuite     → *server.Hertz
  │
  ├── BuildHertzServerOptions     → group:"aghertz_server_options"
  │
  ├── NewFxServerMiddlewareProvider → group:"aghertz_middleware"
  │     └── metadata.NewAgHertzServerAgMetadataMiddleware
  │
  ├── FxNewServerConfigurator     → *ServerConfigurator
  │     └── 依赖: *server.Hertz + group options + group routes + group middlewares
  │
  ├── NewAGHertzServer           → *AgHertzServer
  └── hertzServerWrapper         → group:"ag_servers" (被 ag-app 发现)

FxModuleAgHertzClient           ← Client Module (zfx_client_hertz.go)
  ├── discovery.FxHertzResolverModule ← Nacos 服务发现 (可选)
  │     └── nacos.FxNacosResolverModule
  ├── NewClientProperties        → *HertzClientProperties
  ├── BuildClientOptionWithConfig → group:"aghertz_client_options"
  ├── BuildMiddlewareOptionWithConfig → PrioritizedClientMiddlewareSuite
  │
  ├── FxNewHertzClientParams     → *HertzClientParams
  │     └── 依赖: properties + group options + group middlewares + resolver
  │
  ├── NewHertzClient             → *client.Client
  └── NewFxClientMiddlewareProvider → group:"aghertz_client_middleware"
        └── metadata.NewAgHertzClientAgMetadataMiddleware
```

## 1. Server FX Module (`zfx_server_hertz.go`)

```go
// zfx_server_hertz.go:15-57
var FxAgHertzServerModule = fx.Module("fx_aghertz_server",
    // 注册中心
    registry.FxHertzRegistyModule,

    fx.Provide(
        NewHertzServerProperties,          // 配置
        FxNewHertzServerConfigParam,       // 参数聚合
        NewFxServerConfigOptionsProvider(BuildHertzServerConfigOption), // Hertz 原生选项
        FxNewHertsServerConfigSuite,       // ConfigSuite 聚合
        NewHertzServerWithSuite,           // *server.Hertz
        NewFxServerOptionsProvider(BuildHertzServerOptions), // 增强选项
        NewFxServerMiddlewareProvider(metadata.NewAgHertzServerAgMetadataMiddleware),
        FxNewServerConfigurator,           // ServerConfigurator
        NewAGHertzServer,                  // AgHertzServer
        hertzServerWrapper,                // → group:"ag_servers"
    ),

    fx.Invoke(func(sc *ServerConfigurator) error {
        return sc.InitHertzServer()         // 初始化
    }),
)
```

### 注入组标签

| 组标签 | 类型 | 提供者 |
|--------|------|--------|
| `aghertz_server_config_options` | `*config.Option` | `NewFxServerConfigOptionsProvider` |
| `aghertz_server_options` | `*ServerOption` | `NewFxServerOptionsProvider` |
| `aghertz_route` | `*Route` | `NewFxServerRouteProvider` |
| `aghertz_middleware` | `Middleware` + `app.HandlerFunc` | `NewFxServerMiddlewareProvider` |
| `ag_servers` | `ag_server.Server` | `hertzServerWrapper`（被 ag-app 发现） |

## 3. 完整装配示例

```go
import (
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    ahserver "gitlab.allinfinance.com/aifgo/ag-core/contribute/aghertz/server"
    ahclient "gitlab.allinfinance.com/aifgo/ag-core/contribute/aghertz/client"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/aghertz/aghertzclient"
)

func main() {
    app := fxs.FxAppMode(
        // ag-core 基础模块（配置、日志等）
        fxs.FxAgConfModule,
        fxs.FxAgSlogModule,

        // Hertz Server
        ahserver.FxAgHertzServerModule,

        // 注册路由
        fx.Provide(
            ahserver.NewFxServerRouteProvider(
                func() *ahserver.Route {
                    return ahserver.NewRoute("GET", "/api/v1/hello",
                        handlers.HelloHandler,
                    )
                },
            ),
        ),

        // Hertz Client
        ahclient.FxModuleAgHertzClient,

        // 注册自定义业务中间件
        ahclient.NewFxClientMiddlewareProvider(
            func() client.Middleware {
                return myMiddleware
            },
        ),
    )
    app.Run()
}
```

## 4. 依赖关系

```
FxAppMode
  ├── FxAgConfModule        (配置)
  │
  ├── FxAgHertzServerModule (Server)
  │   ├── registry.FxHertzRegistyModule
  │   │   └── nacos.FxNacosRegistyModule ← INamingClient
  │   │
  │   └── 各 Provide + Invoke 如上
  │
  ├── FxModuleAgHertzClient (Client)
  │   ├── discovery.FxHertzResolverModule
  │   │   └── nacos.FxNacosResolverModule ← INamingClient
  │   │
  │   └── 各 Provide 如上
  │
  └── 用户注册的路由/中间件（通过 group 注入）
```

> **注意**：Nacos 注册和发现均依赖 `naming_client.INamingClient`，该对象由外部 Nacos 模块（`agnacos`）提供，需确保在 `FxAgHertzServerModule` / `FxModuleAgHertzClient` 之前注册。
