# 基础客户端与序列化

> 路径：`aghertzclient/` | 面向业务调用的 HTTP 客户端封装

## 概述

`aghertzclient` 包提供 `HertzBaseClient`，在 Hertz `*client.Client` 之上封装了**请求构建**、**路径参数替换**、**序列化器**、**响应解析**等能力，简化 HTTP 调用。

## 文件列表

| 文件 | 职责 |
|------|------|
| `aghertz_base_client.go` | HertzBaseClient：DoRequest、请求构建、响应解析 |
| `serializer.go` | Serializer 接口 + JSON / Protobuf 实现 |

---

## 1. HertzBaseClient

### 结构定义

```go
// aghertz_base_client.go:29-37
type HertzBaseClient struct {
    endpoint string        // 服务端点（服务名或完整 URL）
    isSD     bool          // 是否启用服务发现
    cli      *client.Client
}

type RequestParam struct {
    Method      string            // HTTP 方法
    Path        string            // 路径，如 /api/v1/users/:id
    PathVars    map[string]string // 路径参数
    QueryParams map[string]string // 查询参数
    ContentType string            // 内容类型
    Serializer  Serializer        // 序列化器
}
```

### 构造函数

```go
// aghertz_base_client.go:40-52
func NewHertzBaseClient(cli *client.Client, opts ...AgHertzClientOption) *HertzBaseClient
```

支持 Option 模式配置：

```go
func WithSD(isSD bool) AgHertzClientOption                          // 启用服务发现
func WithEndpoint(endpoint string) AgHertzClientOption              // 设置端点
func WithSDEndpoint(endpoint string) AgHertzClientOption            // 设置端点+服务发现
func WithDirectEndpoint(endpoint string) AgHertzClientOption        // 设置端点+直连
```

### DoRequest — 核心请求方法

```go
// aghertz_base_client.go:80-143
func (c *HertzBaseClient) DoRequest(
    ctx context.Context,
    reqParam *RequestParam,   // 请求参数
    req interface{},          // 请求体对象
    resp interface{},         // 响应体对象（指针）
    opts ...config.RequestOption,
) error
```

**执行流程**：

```
DoRequest(ctx, reqParam, req, resp)
    │
    ├── 1. buildRequestURLAndOptions
    │       ├── 替换路径参数 :id → value
    │       ├── 构建 baseURL（http:// + endpoint）
    │       ├── 路径拼接（处理双斜杠）
    │       ├── 服务发现选项（isSD → WithSD(true)）
    │       └── 返回完整 URL + requestOpts
    │
    ├── 2. 创建 protocol.Request
    │       ├── Method, URL
    │       └── 设置请求头
    │
    ├── 3. serializeRequestBody
    │       ├── 优先使用 reqParam.Serializer
    │       ├── 其次根据 ContentType 查找注册的序列化器
    │       └── 默认 JSON（sonic.Marshal）
    │
    ├── 4. 设置 QueryParams
    │
    ├── 5. cli.Do(ctx, preq, res)
    │
    ├── 6. checkResponseStatus
    │       └── 非 200 → 返回错误（含状态码+响应体）
    │
    └── 7. parseResponseBody
            └── JSON Unmarshal → resp
```

### URL 构建智能路径拼接

```go
// aghertz_base_client.go:193-206
if rpath == "" {
    rurl = strings.TrimSuffix(baseURL, "/")          // 空路径，去掉结尾 /
} else if strings.HasSuffix(baseURL, "/") && strings.HasPrefix(rpath, "/") {
    rurl = baseURL + rpath[1:]                       // 防双斜杠
} else if !strings.HasSuffix(baseURL, "/") && !strings.HasPrefix(rpath, "/") {
    rurl = baseURL + "/" + rpath                     // 补斜杠
} else {
    rurl = baseURL + rpath                           // 正常拼接
}
```

避免 `http://service//api/v1/users` 这样的路径问题。

## 2. Serializer — 序列化器

### 接口

```go
// serializer.go:33-36
type Serializer interface {
    Marshal(v interface{}) ([]byte, error)
    ContentType() string
}
```

### 内置实现

| 序列化器 | Content-Type | 库 |
|---------|-------------|-----|
| JsonSerializer | `application/json` | `github.com/bytedance/sonic` |
| ProtobufSerializer | `application/x-protobuf` | `google.golang.org/protobuf/proto` |

### 注册与获取

```go
// serializer.go:14-30
var Serializers map[string]Serializer = map[string]Serializer{
    MIMEApplicationJSON: &JsonSerializer{},
    MIMEPROTOBUF:        &ProtobufSerializer{},
}

func GetSerializer(contentType string) Serializer
func RegisterSerializer(contentType string, serializer Serializer)
```

支持扩展：调用 `RegisterSerializer("application/xml", &XmlSerializer{})` 即可注册自定义序列化器。

## 3. 使用示例

```go
// 创建基础客户端
baseClient := aghertzclient.NewHertzBaseClient(
    hertzClient,
    aghertzclient.WithSDEndpoint("my-service"),  // 服务发现模式
)

// 发起请求
var resp GetUserResponse
err := baseClient.DoRequest(ctx, &aghertzclient.RequestParam{
    Method:   "GET",
    Path:     "/api/v1/users/:id",
    PathVars: map[string]string{"id": "123"},
}, nil, &resp)
```
