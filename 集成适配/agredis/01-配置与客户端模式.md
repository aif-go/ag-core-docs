# 配置与客户端模式

> 文件：`config_redis.go` + `config_converter.go` + `ag_client_builder.go` + `rw_client.go`

## 配置结构

```go
// config_redis.go:23-29
type AgRedisProperties struct {
    Type Type                              // "universal" | "rw"
    Config     AgUniversalOptionsProperties  // 主库配置
```

配置前缀：`agredis`

### AgUniversalOptionsProperties

映射 go-redis 的 `redis.UniversalOptions`，所有时间字段单位毫秒：

```yaml
agredis:
  type: universal
  config:
    addrs:
      - 127.0.0.1:6379
    db: 0
    username: ""
    password: ""
    protocol: 0

    # 重试
    maxRetries: 0
    minRetryBackoff: 8        # ms
    maxRetryBackoff: 512      # ms

    # 超时
    dialTimeout: 5000         # ms
    readTimeout: 3000         # ms
    writeTimeout: 3000        # ms
    contextTimeoutEnabled: false

    # 连接池
    poolSize: 10
    poolTimeout: 4000         # ms
    minIdleConns: 0
    maxIdleConns: 0
    maxActiveConns: 0
    connMaxIdleTime: 300000   # ms
    connMaxLifetime: 0

    # 集群
    maxRedirects: 0
    readOnly: false
    routeByLatency: false
    routeRandomly: false

    # Sentinel
    masterName: ""
    sentinelUsername: ""
    sentinelPassword: ""
```

## 客户端模式

### Universal 模式

```yaml
agredis:
  type: universal
  config:
    addrs:
      - 127.0.0.1:6379
```

创建流程：
```go
func (b *AgRedisClientBuilder) buildUniversalClient() (AgRedisClient, error) {
    conf := b.Config.Config
    options := NewUniversalOptionsWithAgUniversalProperties(conf)
    cli := redis.NewUniversalClient(options)
    return cli, nil
}
```

`redis.UniversalClient` 自动根据 `Addrs` 配置识别：
- 单个地址 + 无 MasterName → 单机模式
- 多个地址 → 集群模式
- 有 MasterName → Sentinel 模式

### RW 模式（读写分离）

```yaml
agredis:
  type: rw
  config:                         # 主节点
    addrs:
      - master:6379
  replicas:                       # 从节点（可多个）
    - addrs:
      - slave1:6379
    - addrs:
      - slave2:6379
```

#### RWClient 结构

```go
// rw_client.go:20-24
type RWClient struct {
    redis.UniversalClient   // 主节点：所有写操作 + 默认 API
    slaves map[string]redis.UniversalClient  // 从节点：读操作
}
```

#### 读写分离策略

**读操作** → 随机从节点：
```go
// rw_client_string_cmdable.go:51-54
func (c *RWClient) Get(ctx context.Context, key string) *redis.StringCmd {
    slave := c.getRandomSlave()
    return slave.Get(ctx, key)
}
```

**写操作** → 由嵌入的 `redis.UniversalClient` 自动处理（即主节点）。

已实现的路由到从节点的命令：

| 类型 | 命令 |
|------|------|
| String | `Get`, `GetRange`, `GetEx`, `MGet`, `StrLen` |
| Hash | `HGet`, `HMGet`, `HExists`, `HGetAll`, `HKeys`, `HLen`, `HVals`, `HStrLen`, `HRandField` |
| Generic | `Exists`, `Type`, `TTL`, `PTTL`, `ExpireTime`, `PExpireTime`, `RefCount`, `ObjectFingerprint`, `Dump`, `Touch` |
| SortedSet | `ZCount`, `ZLexCount`, `ZScore`, `ZRank`, `ZRevRank`, `ZCard`, `ZRange`, `ZRangeWithScores`, `ZRangeByScore`, `ZRevRange`, `ZRevRangeWithScores`, `ZRevRangeByScore`, `ZRangeByLex`, `ZRevRangeByLex`, `ZMScore` |

未覆盖的命令默认走主节点（嵌入的 `UniversalClient`）。

#### 健康检查

`Ping` 和 `Echo` 会额外校验从节点：
- 主节点不可用 → 立即失败
- 主节点可用但**所有从节点不可用** → 视为整体不可用（返回 `RWClient unhealthy`）
- 主节点 + 至少一个从节点可用 → 正常

```go
// rw_client.go:44-77
func (c *RWClient) Ping(ctx context.Context) *redis.StatusCmd {
    // 主节点 Ping
    mResult := c.UniversalClient.Ping(ctx)
    if mResult.Err() != nil {
        return mResult
    }
    // 快速检查从库（200ms 超时）
    slaveOK := false
    for _, slave := range c.slaves {
        if slave.Ping(tctx).Err() == nil {
            slaveOK = true
            break
        }
    }
    if !slaveOK {
        // 视为不可用
        fakeCmd.SetErr(errors.New("RWClient unhealthy: master is up but all slaves are down"))
        return fakeCmd
    }
    return mResult
}
```

#### Hook 广播

```go
// rw_client_hook.go:8-13
func (c *RWClient) AddHook(hook redis.Hook) {
    c.UniversalClient.AddHook(hook)
    for _, slave := range c.slaves {
        slave.AddHook(hook)
    }
}
```

Hook 同时注册到主节点和所有从节点。

#### 直接访问主从

```go
func (c *RWClient) Master() AgRedisClient
func (c *RWClient) Slaves() map[string]AgRedisClient
```

用于需要直接控制路由的场景。

## Builder

```go
// ag_client_builder.go:10-12
type AgRedisClientBuilder struct {
    Config *AgRedisProperties
}

func (b *AgRedisClientBuilder) Build() (AgRedisClient, error) {
    switch b.Config.Type {
    case TypeUniversal: return b.buildUniversalClient()
    case TypeRW:        return b.buildRWClient()
    }
}
```

`buildUniversalCli` 有 `panic` 保护（`defer recover`），确保创建失败时已创建的连接被正确关闭。
