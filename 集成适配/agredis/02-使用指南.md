# AgRedis 使用指南

> 面向业务开发者：快速上手、配置、基本操作、最佳实践

---

## 快速开始

### 1. 注册 FX 模块

```go
import (
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    "gitlab.allinfinance.com/aifgo/ag-core/contribute/agredis"
)

func main() {
    app := fxs.FxAppMode(
        fxs.FxAgConfModule,
        agredis.FxAgRedisServerMode,
    )
    app.Run()
}
```

### 2. 注入 AgRedisClient

```go
type UserService struct {
    redis agredis.AgRedisClient
}

func NewUserService(cli agredis.AgRedisClient) *UserService {
    return &UserService{redis: cli}
}
```

## 配置

### 单机模式

```yaml
agredis:
  type: universal
  config:
    addrs:
      - 127.0.0.1:6379
    db: 0
    poolSize: 10
```

### 集群模式

```yaml
agredis:
  type: universal
  config:
    addrs:
      - node1:6379
      - node2:6379
      - node3:6379
```

### Sentinel 模式

```yaml
agredis:
  type: universal
  config:
    addrs:
      - sentinel1:26379
      - sentinel2:26379
    masterName: mymaster
    sentinelUsername: ""
    sentinelPassword: ""
```

### 读写分离模式

```yaml
agredis:
  type: rw
  config:
    addrs:
      - master:6379
    poolSize: 20
  replicas:
    - addrs:
      - slave1:6379
    - addrs:
      - slave2:6379
```

## 基本操作

### String

```go
// Set
err := cli.Set(ctx, "key", "value", 0).Err()

// Set with TTL
err := cli.Set(ctx, "session:123", userData, 30*time.Minute).Err()

// Get
val, err := cli.Get(ctx, "key").Result()

// MGet
vals, err := cli.MGet(ctx, "key1", "key2").Result()

// Incr
count, err := cli.Incr(ctx, "counter").Result()

// SetNX（分布式锁）
locked, err := cli.SetNX(ctx, "lock:order", "1", 10*time.Second).Result()
```

### Hash

```go
// HSet
err := cli.HSet(ctx, "user:1", map[string]interface{}{
    "name": "Alice",
    "age":  30,
}).Err()

// HGet
name, err := cli.HGet(ctx, "user:1", "name").Result()

// HGetAll
user, err := cli.HGetAll(ctx, "user:1").Result()

// HDel
err := cli.HDel(ctx, "user:1", "age").Err()
```

### List

```go
// LPush
err := cli.LPush(ctx, "queue:tasks", taskJSON).Err()

// RPop
task, err := cli.RPop(ctx, "queue:tasks").Result()

// LLen
length, err := cli.LLen(ctx, "queue:tasks").Result()
```

### Set

```go
// SAdd
err := cli.SAdd(ctx, "set:tags", "golang", "redis", "microservice").Err()

// SMembers
members, err := cli.SMembers(ctx, "set:tags").Result()

// SIsMember
exists, err := cli.SIsMember(ctx, "set:tags", "golang").Result()
```

### ZSet

```go
// ZAdd
err := cli.ZAdd(ctx, "leaderboard", redis.Z{
    Score:  100.0,
    Member: "player1",
}).Err()

// ZRangeByScore（读操作，RW 模式下走从节点）
results, err := cli.ZRangeByScore(ctx, "leaderboard", &redis.ZRangeBy{
    Min: "0",
    Max: "100",
}).Result()

// ZRank
rank, err := cli.ZRank(ctx, "leaderboard", "player1").Result()
```

### 通用

```go
// Del
err := cli.Del(ctx, "key1", "key2").Err()

// Exists（读操作，RW 模式下走从节点）
exists, err := cli.Exists(ctx, "key").Result()

// Expire
err := cli.Expire(ctx, "key", 24*time.Hour).Result()

// TTL（读操作，RW 模式下走从节点）
ttl, err := cli.TTL(ctx, "key").Result()
```

## RW 模式说明

### 读写自动路由

```go
// 以下操作自动走从节点（随机选择）
cli.Get(ctx, "key")
cli.MGet(ctx, "keys...")
cli.HGet(ctx, "key", "field")
cli.Exists(ctx, "keys...")
cli.ZRangeByScore(ctx, "key", &zrangeby)

// 以下操作自动走主节点（嵌入的 UniversalClient）
cli.Set(ctx, "key", "value", 0)
cli.Del(ctx, "key")
cli.HSet(ctx, "key", "field", "value")
cli.Expire(ctx, "key", ttl)
cli.Incr(ctx, "key")
```

### 直接访问主从

```go
// 直接操作主节点（写入）
master := cli.Master()
master.Set(ctx, "key", "value", 0)

// 直接操作从节点（读取）
slaves := cli.Slaves()
for id, slave := range slaves {
    val, _ := slave.Get(ctx, "key").Result()
}
```

## 生命周期管理

FX 模块自动注册了生命周期钩子：
- **OnStop**：关闭 Redis 连接（`client.Close()`）
- **OnStart**：预留了健康检查入口（当前为空实现）

不需要手动调用 `Close()`，应用退出时 FX 自动处理。

## 最佳实践

### ✅ 接口编程

```go
// 依赖接口而非具体实现
type MyService struct {
    redis agredis.AgRedisClient  // 接口
}
```

`AgRedisClient` 接口屏蔽了单机/集群/RW 的差异，切换模式只需改配置，无需改代码。

### ✅ Universal 模式优先

除非明确需要读写分离，优先使用 `type: universal`。`redis.UniversalClient` 会自动适配单机、集群、Sentinel 三种部署模式。

### ✅ RW 模式的从节点健康

`Ping` / `Echo` 会校验从节点可用性——如果从节点全挂，整体会被标记为不可用。部署时确保至少有一个健康的从节点。

### ❌ 避免频繁创建连接

```go
// ❌ 每次操作创建新客户端
func DoSomething() {
    cli := redis.NewClient(&redis.Options{Addr: "..."})
    defer cli.Close()
    cli.Get(ctx, "key")
}

// ✅ 通过 FX 注入单例客户端
type MyService struct {
    redis agredis.AgRedisClient  // 单例，由 FX 管理生命周期
}
```

## FAQ

**Q: 如何检查 Redis 连接状态？**
A: 使用 `Ping()`，RW 模式下会同时校验主从节点：
```go
err := cli.Ping(ctx).Err()
```

**Q: 如何使用连接池统计？**
A:
```go
stats := cli.PoolStats()
// stats.Hits, stats.Misses, stats.Timeouts, stats.TotalConns, stats.IdleConns
```

**Q: 如何切换数据库？**
A: 配置 `config.db: 1`。如果需要运行时切换，go-redis 的 `CLIENT SETNAME` 只能在连接时设置，建议连接池维度隔离，通过不同的配置创建不同 DB 的客户端。
