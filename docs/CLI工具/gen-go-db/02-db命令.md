# gen-go-db db 命令详解

> 功能：从 YAML 定义文件生成 Go Model + DAO + 命名 SQL 代码

## 用途

消费 `gen-go-db yaml` 生成的（或人工编写的）YAML 表定义文件，输出完整的 Go 数据库访问层代码，包括 ORM Model 结构体、DAO CRUD 方法、命名 SQL 定义以及数据库特化 SQL。

## 命令格式

```bash
gen-go-db db -i <yaml-path> -o <output-dir> [options]
```

## 参数清单

| 参数 | 缩写 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|:----:|--------|------|
| `--input` | `-i` | string | ✅ | — | YAML 文件路径或目录 |
| `--output` | `-o` | string | ✅ | — | 输出基础目录（自动拼接 `repository/model/` 和 `repository/dao/`） |
| `--table` | `-T` | string | ❌ | 全部表 | 指定表名，逗号分隔多个 |
| `--module` | `-m` | string | ❌ | 从 `go.mod` 读取 | 项目模块名，影响 import 路径 |
| `--dbtype` | `-d` | string | ❌ | mysql+db2 | 数据库类型：`mysql` / `db2` |

> ⚠️ **`-m` 参数必须指定**，它决定生成代码中 `import` 路径的根模块。不指定时尝试从 `go.mod` 读取。

## 使用示例

```bash
# 基本用法：YAML 目录 → 全部表
gen-go-db db -i ./repository/yaml -o ./ -m myproject

# 单文件
gen-go-db db -i ./repository/yaml/TM_USER.yaml -o ./ -m myproject

# 指定表名
gen-go-db db -i ./repository/yaml -o ./ -m myproject -T TM_USER

# 只生成 MySQL 类型
gen-go-db db -i ./repository/yaml -o ./ -m myproject -d mysql

# 组合使用
gen-go-db db -i ./repository/yaml/TM_USER.yaml -o ./ -m myproject -d mysql -T TM_USER
```

## 输出文件清单

对于表 `STUDENT`，生成 6 个文件：

```
repository/
├── model/
│   └── student_model.go              ← Model 定义
└── dao/
    ├── student_dao.go                ← DAO CRUD + 命名 SQL 执行
    ├── student_constant.go           ← 命名 SQL 信息注册
    ├── student_namingsql.go          ← 命名 SQL 初始化入口
    ├── mysql_student_namingsql.go    ← MySQL 特定 SQL
    └── db2_student_namingsql.go      ← DB2 特定 SQL
```
