# FX 集成

> 文件：`zfx_agsarama.go`

## 模块结构

```
FxAgsaramaModule ──► AgsaramaModuleFx
                        │
                        ├── 入参 FxParams
                        │     ├── Binder    (ag_conf.IBinder)
                        │     └── ConfigOpts[] (group:"agsarama")
                        │
                        ├── NewAgsaramaConfig(binder) → *Config
                        ├── TransConfigToSaramaConfig(cfg) → *sarama.Config
                        ├── ExtendSaramaConfigWithOptions(sconf, opts...)
                        ├── NewClientWithAgConfig(cfg) → sarama.Client
                        │
                        └── 出参 FxResult
                              ├── Config       (*Config)
                              ├── SaramaConfig (*sarama.Config)
                              └── Client       (sarama.Client)
```


## FxParams — 入参

```go
// zfx_agsarama.go:17-25
type FxParams struct {
    fx.In

    Binder     ag_conf.IBinder           // 配置绑定器
    ConfigOpts []ConfigOption `group:"agsarama",optional:"true"`  // 扩展选项
}
```

## FxResult — 出参

```go
// zfx_agsarama.go:28-34
type FxResult struct {
    fx.Out

    Config       *Config        // agsarama 友好配置
    SaramaConfig *sarama.Config // 转换后的 Sarama 原生配置
    Client       sarama.Client  // Sarama 客户端
}
```

## 执行流程

```go
// zfx_agsarama.go:37-70
func AgsaramaModuleFx(params FxParams) (FxResult, error) {
    // 1. 从 YAML 绑定 Config
    cfg, err := NewAgsaramaConfig(params.Binder)

    // 2. 转换为 sarama.Config
    sconf, err := TransConfigToSaramaConfig(cfg)

    // 3. 应用自定义配置选项（FX 组注入）
    if len(params.ConfigOpts) > 0 {
        ExtendSaramaConfigWithOptions(sconf, params.ConfigOpts...)
    }

    // 4. 创建 sarama.Client
    client, err := NewClientWithAgConfig(cfg)

    return FxResult{Config: cfg, SaramaConfig: sconf, Client: client}, nil
}
```

## 组标签注入

```go
// zfx_agsarama.go:72-77
func FxAgsaramaGroupTag(t any) any {
    return fx.Annotate(
        t,
        fx.ResultTags(`group:"agsarama"`),
    )
}
```

用于注入额外的 `ConfigOption` 到 `ConfigOpts` 切片中。

## 装配示例

```go
import (
    "github.com/aif-go/ag-core/fxs"
    "github.com/aif-go/ag-core/contribute/agsarama"
    "github.com/IBM/sarama"
)

func main() {
    app := fxs.FxAppMode(
        fxs.FxAgConfModule,
        fxs.FxAgSlogModule,

        agsarama.FxAgsaramaModule,

        // 自定义 Sarama 配置扩展
        fx.Provide(
            agsarama.FxAgsaramaGroupTag(func() agsarama.ConfigOption {
                return func(conf *sarama.Config) error {
                    conf.Producer.Return.Successes = true
                    return nil
                }
            }),
        ),
    )
    app.Run()
}
```

## 注入后的使用

```go
type MyService struct {
    kafkaClient sarama.Client
}

func NewMyService(client sarama.Client) *MyService {
    return &MyService{kafkaClient: client}
}
```

> 注：`FxAgsaramaModule` 注册 3 个类型到容器：`*agsarama.Config`、`*sarama.Config`、`sarama.Client`，按需直接注入即可。
