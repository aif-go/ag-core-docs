# 配置

> 文件：`config.go` | 核心配置结构体与 Sarama 转换

## Config 结构体

```go
// config.go:13-27
type Config struct {
    Brokers []string          // Kafka broker 地址列表

    Admin    ConfigAdmin      // Admin 相关配置
    Net      ConfigNet        // 网络相关配置（含 SASL）
    Metadata ConfigMetadata   // 元数据相关配置
    Producer ConfigProducer   // 生产者配置
    Consumer ConfigConsumer   // 消费者配置

    ClientID           string  // 客户端标识符，默认 "agsarama"
    RackID             string  // 机架标识符
    ChannelBufferSize  int     // 通道缓冲区大小，默认 256
    ApiVersionsRequest bool    // 是否发送 ApiVersions 请求，默认 true
    Version            string  // Kafka 版本，默认 Sarama 默认版本
}
```

配置前缀：`agsarama`

所有时间字段单位为**毫秒**（ms）。

type ConfigNet struct {

## 类型枚举

所有枚举均实现 `ToSarama()` 方法，将字符串常量转换为 Sarama 内部类型。

### RequiredAcks

| 字符串 | Sarama 常量 | 含义 |
|--------|-------------|------|
| `no_response` | `NoResponse` | 不等待确认 |
| `wait_for_local` | `WaitForLocal` | 等待 Leader 确认（默认） |
| `wait_for_all` | `WaitForAll` | 等待所有 ISR 确认 |

### CompressionCodec

| 字符串 | Sarama 常量 | 说明 |
|--------|-------------|------|
| `none` | `CompressionNone` | 不压缩（默认） |
| `gzip` | `CompressionGZIP` | gzip |
| `snappy` | `CompressionSnappy` | Snappy |
| `lz4` | `CompressionLZ4` | LZ4 |
| `zstd` | `CompressionZSTD` | Zstandard |

### SASLMechanism

| 字符串 | 含义 |
|--------|------|
| `plain` | SASL/PLAIN |
| `scram-sha-256` | SCRAM SHA-256 |
| `scram-sha-512` | SCRAM SHA-512 |
| `oauth` | OAuth Bearer |
| `gssapi` | GSSAPI (Kerberos) |

### IsolationLevel

| 字符串 | Sarama 常量 | 含义 |
|--------|-------------|------|
| `read_uncommitted` | `ReadUncommitted` | 读未提交（默认） |
| `read_committed` | `ReadCommitted` | 读已提交（仅消费已提交事务消息） |

### PartitionerType

分区器，字符串枚举，**大小写不敏感**（`strings.ToLower` 归一化匹配）。

| 字符串 | 分区器 | 说明 |
|--------|--------|------|
| `hash` | `NewHashPartitioner`（默认） | 按消息 key 的 hash 值分区。如果未设置 key，则随机选择分区 |
| `manual` | `NewManualPartitioner` | 手动指定分区。通过 `message.PartitionKey` 指定目标分区 |
| `random` | `NewRandomPartitioner` | 随机分区 |
| `roundrobin` | `NewRoundRobinPartitioner` | 轮询分区 |

> ✅ **大小写不敏感**：写 `manual`、`Manual`、`MANUAL` 均可正确匹配。无效值返回 `error`，不再静默降级。

## ToSaramaConfig 转换

```go
// config.go:362-483
func (c *Config) ToSaramaConfig() (*sarama.Config, error)
```

将 agsarama 的 `Config` 完整映射为 `sarama.Config`，覆盖：

| 配置域 | 映射关系 |
|--------|---------|
| Admin | `Retry.Max`, `Retry.Backoff`, `Timeout` |
| Net | `MaxOpenRequests`, `DialTimeout`, `ReadTimeout`, `WriteTimeout`, `KeepAlive`, `SASL.*` |
| Metadata | `Retry.Max`, `Retry.Backoff`, `RefreshFrequency`, `Full`, `Timeout`, `AllowAutoTopicCreation`, `SingleFlight` |
| Producer | `MaxMessageBytes`, `RequiredAcks`, `Timeout`, `Compression`, `CompressionLevel`, `Partitioner`, `Idempotent`, `Transaction.*`, `Return.*`, `Flush.*`, `Retry.*` |
| Consumer | `Group.Session.Timeout`, `Group.Heartbeat.Interval`, `Group.Rebalance.*`, `Fetch.*`, `MaxWaitTime`, `MaxProcessingTime`, `Offsets.*`, `IsolationLevel` |
| 全局 | `ClientID`, `RackID`, `ChannelBufferSize`, `ApiVersionsRequest`, `Version` |

**版本解析**：`Version` 字符串通过 `sarama.ParseKafkaVersion()` 解析。

## 默认值汇总

参见 `NewDefaultConfig()`（config.go:283-359），关键默认值：

| 字段 | 默认值 | 说明 |
|------|--------|------|
| Brokers | `[]` | **必须配置** |
| ClientID | `"agsarama"` | 客户端 ID |
| Timeout 系列 | 30s | Dial/Read/Write |
| SASL | 禁用 | 需显式 `enable: true` |
| Producer.RequiredAcks | `wait_for_local` | 等待 Leader 确认 |
| Producer.Partitioner | `hash` | 按 key hash 分区 |
| Producer.Compression | `none` | 不压缩 |
| Producer.Return.Errors | `true` | 返回错误通道 |
| Consumer.Offsets.Initial | `-1` | `OffsetNewest`（从最新开始消费） |
| Consumer.Offsets.AutoCommit | `true`, 1s | 自动提交偏移量 |
| Consumer.Group.Session | 10s | 会话超时 |
| Consumer.IsolationLevel | `read_uncommitted` | 读未提交 |
