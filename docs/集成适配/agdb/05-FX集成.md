# FX 集成

> 文件：`zfx_agdb.go` + `gormdb/zfx_aicgormdb.go` + `agdao/zfx_dao.go`

agdb 通过三个 FX Module 组织依赖注入：

## 模块结构

```
▸ FxAgDbModule             ← 顶层 agdb 模块 (zfx_agdb.go)
  ├── 事务中间件             → TransactionMiddlewareProvider
  ├── 事务预处理             → TransactionPreOpt
  └── DAO 基础能力           → agdao.FxNewAgGormBaseDao
      └── 依赖: []TbInfoOpt (group:"fx_ag_gorm_tbinfo_opt")

▸ FxAicGromdbModule        ← GORM 子模块 (zfx_aicgormdb.go)
  ├── NewAggormDbConfig     → *Config
  ├── NewDB_V2              → *gorm.DB        (依赖 Config + logger)
  ├── NewRepository         → *Repository      (依赖 *gorm.DB)
  ├── NewTransactionManager → agdb.TransactionManager (依赖 Repository)
  └── FindGormLoggerFromAgslog → logger.Interface (依赖 Config)
```

---

## 1. gormdb FX 模块 (`zfx_aicgormdb.go`)

```go
// zfx_aicgormdb.go:19-28
var FxAicGromdbModule = fx.Module("fx_aic_gormdb",
    fx.Provide(
        NewAggormDbConfig,         // Config → 从环境绑定
        NewDB_V2,                  // *gorm.DB → 数据库连接
        NewRepository,             // *Repository → 数据访问
        NewTransactionManager,     // agdb.TransactionManager → 事务管理器
        FindGormLoggerFromAgslog,  // logger.Interface → GORM 日志
    ),
)
```

**依赖链**：
```
Config ──► NewDB_V2 ──► *gorm.DB ──► NewRepository ──► *Repository
                              │                        │
                              ▼                        ▼
                    FindGormLoggerFromAgslog    NewTransactionManager
                              │                        │
                              ▼                        ▼
                    logger.Interface           agdb.TransactionManager
```

---

## 2. agdb FX 模块 (`zfx_agdb.go`)

```go
// zfx_agdb.go:10-27
var FxAgDbModule = fx.Module("fx_agdb_module",
    fx.Provide(
        // 1. 注册事务中间件（全局中间件）
        ag_service.NewFxAgGlobalMiddleware(
            NewTransactionMiddlewareProvider,  // 依赖 TransactionManager
        ),
        // 2. 注册事务预处理（CallInfo 标记解析）
        ag_service.NewFxAgCallInfoOpt(
            func() ag_service.CallInfoOpt {
                return TransactionPreOpt
            },
        ),
        // 3. 基础 DAO 增强能力
        agdao.FxNewAgGormBaseDao,
    ),
)
```

依赖 `agdb.TransactionManager`，由 `FxAicGromdbModule` 的 `NewTransactionManager` 提供。

## 3. agdao FX 模块 (`zfx_dao.go`)

```go
// agdao/zfx_dao.go:5-24
type FxInBaseDao struct {
    fx.In
    TbInfoOpts []TbInfoOpt `group:"fx_ag_gorm_tbinfo_opt",optional:"true"`
}

func FxNewAgGormBaseDao(in FxInBaseDao) (BaseDao, error) {
    bdao := &baseDao{}
    bdao.RegTbInfoOpt(in.TbInfoOpts...)  // 注册所有表信息选项
    return bdao, nil
}
```

**组标签**：允许其他模块通过 `fx.Annotate` 注入表名策略：

```go
// agdao/zfx_dao.go:12-17
func NewFxAgTbInfoOpt(t any) any {
    return fx.Annotate(
        t,
        fx.ResultTags(`group:"fx_ag_gorm_tbinfo_opt"`),
    )
}
```

其他模块注册表名策略的示例：
```go
fx.Provide(
    NewFxAgTbInfoOpt(func() TbInfoOpt {
        return WithTbNameStrategy(func(ctx context.Context, info *TableInfo) string {
            return info.TableName + "_" + GetTenant(ctx)
        })
    }),
)
```

## 4. 应用装配

```go
app := fxs.FxAppMode(
    // ... 其他模块
    gormdb.FxAicGromdbModule,  // 先提供 *gorm.DB / Repository / TransactionManager
    agdb.FxAgDbModule,         // 后注册事务中间件（依赖 TransactionManager）
)
```

**顺序要求**：`FxAicGromdbModule` 必须在 `FxAgDbModule` 之前注册，因为后者依赖 `TransactionManager`。

## 5. 依赖关系图

```
fx.Invoke(FxAppMode)
  ├── FxAgConfModule        (配置)
  │   └── IBinder, IConfigurableEnvironment
  │
  ├── FxAicGromdbModule     (GORM 数据库)
  │   ├── ag_conf.IBinder ──► NewAggormDbConfig ──► *Config
  │   ├── *Config ──► NewDB_V2 ──► *gorm.DB
  │   ├── *Config ──► FindGormLoggerFromAgslog ──► logger.Interface
  │   ├── *gorm.DB ──► NewRepository ──► *Repository
  │   └── *Repository ──► NewTransactionManager ──► agdb.TransactionManager
  │
  ├── FxAgDbModule          (事务 + DAO)
  │   ├── TransactionManager ──► NewTransactionMiddlewareProvider
  │   │                            └── MiddlewareProvider
  │   └── agdao.FxNewAgGormBaseDao ──► BaseDao
  │       └── group:"fx_ag_gorm_tbinfo_opt" ──► TbInfoOpt[]
  │
  └── FxAgSlogModule / FxAgSlogZapMode  (日志)
```
