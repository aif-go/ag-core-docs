# FX 集成

> 文件：`zfx_kitex_server.go` + `zfx_kitex_client.go` + `registry/zfx_registy.go`

## 模块结构

```
FxKitexServerBaseModule               ← Server Module (zfx_kitex_server.go)
  ├── registry.FxKitexRegistyModule    ← Nacos 注册
  │     └── nacos.FxNacosRegistyModule ← INamingClient → NewRegisty
  │
  ├── NewKitexServerProperties       → *KitexServerProperties
  ├── FxNewKitexServerSuiteBuilder     → *KitexServerSuiteBuilder
  │     └── 聚合: ServerOptions + Config + Registry + Middlewares
  ├── FxBuilderKitexServerSuite        → *KitexServerSuite
  ├── NewKitexServerWithSuite          → server.Server
  ├── metadata MetaHandler             → group:"kitex_server_options"
  │
  ├── FxNewKitexServiceRegistryHolder  → *AgKitexServiceRegistryHolder
  │     └── 聚合: group:"ag_kitex_service_registry" 的所有服务
  │
  ├── fx.Invoke → FxInvokerKitexServiceRegistryHolder
  │     └── holder.RegisterService(kitexServer) 注册所有服务
  │
  └── NewAgKitexServer                → group:"ag_servers"

FxKitexClientBaseModule               ← Client Module (zfx_kitex_client.go)
  ├── InitKitexClientConfig            → *KitexClientConfig
  ├── BuildKitexResolver              → discovery.Resolver（双模式）
  │     └── 依赖: Config + INamingClient
  ├── FxKitexClientSuiteBuilder        → *KitexSuiteBuilder
  │     └── 聚合: ClientOptions + Config + Resolver + Middlewares
  ├── FxNewKitexClientSuite            → *KitexClientSuite
  └── metadata MetaHandler             → group:"kitex_client_options"
```

## 1. Server FX Module（`zfx_kitex_server.go`）

```go
// zfx_kitex_server.go:15-48
var FxKitexServerBaseModule = fx.Module("fx_kitex_server_base",
    registry.FxKitexRegistyModule,

    fx.Provide(
        NewKitexServerProperties,          // 配置
        FxNewKitexServerSuiteBuilder,      // SuiteBuilder
        FxBuilderKitexServerSuite,         // Suite
        NewKitexServerWithSuite,           // server.Server

        fx.Annotate(
            NewAgKitexServer,
            fx.As(new(ag_server.Server)),
            fx.ResultTags(`group:"ag_servers"`),
        ),

        FxNewKitexServiceRegistryHolder,   // 服务注册 Holder

        NewFxServerOptionsProvider(
            metadata.NewAgKitexServerAgMetadataHTTP2HandlerOption,
        ),
    ),

    fx.Invoke(FxInvokerKitexServiceRegistryHolder),
)
```

### 注入组标签

| 组标签 | 类型 | 提供者 |
|--------|------|--------|
| `kitex_server_options` | `*server.Option` | `NewFxServerOptionsProvider` |
| `kitex_server_middlewares` | `endpoint.Middleware` | `NewFxServerMiddlewareProvider` |
| `kitex_server_prioritized_middlewares` | `PrioritizedServerMiddleware` | `NewFxServerPrioritizedMiddlewareProvider` |
| `ag_kitex_service_registry` | `*AgKitexServiceRegistry` | `NewFxAgKitexServiceRegistry` |
| `ag_servers` | `ag_server.Server` | `fx.Annotate(NewAgKitexServer, ...)` |

## 2. Client FX Module（`zfx_kitex_client.go`）

```go

var FxKitexClientBaseModule = fx.Module("fx_kitex_client_base",
```

## 3. 完整装配示例

```go
import (
    "gitlab.allinfinance.com/aifgo/ag-core/fxs"
    akxserver "gitlab.allinfinance.com/aifgo/ag-core/contribute/agkitex/server"
    akxclient "gitlab.allinfinance.com/aifgo/ag-core/contribute/agkitex/client"
)

func main() {
    app := fxs.FxAppMode(
        // 基础模块
        fxs.FxAgConfModule,
        fxs.FxAgSlogModule,

        // Kitex Server
        akxserver.FxKitexServerBaseModule,

        // 注册 RPC 服务
        fx.Provide(
            akxserver.NewFxAgKitexServiceRegistry(
                func() *akxserver.AgKitexServiceRegistry {
                    return akxserver.NewAgKitexServiceRegistry(
                        myservice.NewServiceInfo(),
                        &MyServiceImpl{},
                    )
                },
            ),
        ),

        // Kitex Client
        akxclient.FxKitexClientBaseModule,

        // 注册自定义中间件
        akxclient.NewFxClientPrioritizedMiddlewareProvider(
            func() client.PrioritizedClientMiddleware {
                return myMiddleware
            },
        ),
    )
    app.Run()
}
```

## 4. 依赖关系

```
FxAppMode
  ├── FxAgConfModule              (配置)
  │
  ├── FxKitexServerBaseModule      (Server)
  │   ├── FxKitexRegistyModule
  │   │   └── FxNacosRegistyModule ← INamingClient
  │   │
  │   └── 各 Provide + Invoke 如上
  │
  ├── FxKitexClientBaseModule      (Client)
  │   └── BuildKitexResolver      ← INamingClient
  │
  └── 用户注册的 RPC Service + 中间件（通过 group 注入）
```

> **注意**：Nacos 注册和发现均依赖 `naming_client.INamingClient`，需确保 `agnacos` 模块在 `FxKitexServerBaseModule` 之前注册。
