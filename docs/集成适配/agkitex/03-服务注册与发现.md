# 服务注册与发现

> 路径：`server/registry/` + `client/resolver.go` + `client/ag_nacos_resolver.go`

## 概述

AgKitex 的服务注册与发现均基于 Nacos。不同于 aghertz 的对称设计，agkitex 的服务端使用官方 Nacos Registry，客户端使用**自定义 AgNacosResolver** 以兼容 Spring gRPC 生态。

```
服务端注册 ──► Nacos Registry (官方)
                 │
              Metadata:
              - gRPC_port: ${port}     ← 兼容 Spring gRPC
              - weight: 1              ← 兼容 grpc-spring
                 │
客户端发现 ──► AgNacosResolver (自定义)
                 │
              解析 gRPC_port 元数据
              还原为真实 gRPC 端口
```

```go

func NewRegisty(param *Param, props *Properties) registry.Registry {
    return nacosreg.NewNacosRegistry(
        param.NamingClient,
        nacosreg.WithGroup(group),
        nacosreg.WithCluster(cluster),
    )

```

依赖 `naming_client.INamingClient`（由 agnacos 模块提供）。

## 服务发现（Client 端）

### 层次

```
client/
├── resolver.go              ← BuildKitexResolver（双模式分发）
└── ag_nacos_resolver.go     ← AgNacosResolver（自定义实现）
```

### AgNacosResolver（`ag_nacos_resolver.go`）

```go
// ag_nacos_resolver.go:39-42
type AgNacosResolver struct {
    cli  naming_client.INamingClient
    opts options  // cluster + group
}
```

实现 `discovery.Resolver` 接口：

| 方法 | 职责 |
|------|------|
| `Target(_, target)` | 返回服务名作为 cache key |
| `Resolve(_, desc)` | 从 Nacos 查询健康实例，解析 Spring gRPC metadata |
| `Diff(cacheKey, prev, next)` | 默认差值计算 |
| `Name()` | 返回 `"nacos:cluster:group"` |

### Resolve 方法

```go
// ag_nacos_resolver.go:71-99
func (n *AgNacosResolver) Resolve(_ context.Context, desc string) (discovery.Result, error) {
    res, err := n.cli.SelectInstances(vo.SelectInstancesParam{
        ServiceName: desc,
        HealthyOnly: true,
        GroupName:   n.opts.group,
        Clusters:    []string{n.opts.cluster},
    })
    // 逐个解析实例
    instances := make([]discovery.Instance, 0, len(res))
    for _, in := range res {
        inst, ok := resolverInstance(in)
        if ok {
            instances = append(instances, inst)
        }
    }
    return discovery.Result{Cacheable: true, CacheKey: desc, Instances: instances}, nil
}
```

### Spring gRPC 兼容（核心）

```go
// ag_nacos_resolver.go:113-143
func resolverInstance(in model.Instance) (discovery.Instance, bool) {
    inPort := in.Port
    metadata := in.Metadata

    // 检查是否是 Spring Cloud 注册的服务
    prs, ok := metadata["preserved.register.source"]
    if ok && prs == "SPRING_CLOUD" {
        // Spring gRPC 将 gRPC 端口放在 metadata 中
        grpcPort, ok := metadata["gRPC_port"]
        if ok {
            p, err := strconv.ParseUint(grpcPort, 10, 64)
            if err == nil {
                inPort = p  // 用 metadata 中的 gRPC_port 覆盖
            }
        }
    }

    return discovery.NewInstance("tcp", fmt.Sprintf("%s:%d", inIp, inPort), int(in.Weight), in.Metadata), true
}
```

**为什么需要自定义 Resolver**：Spring gRPC 服务注册时，实际 gRPC 端口存储在 Nacos 实例的 `metadata["gRPC_port"]` 中，而非直接使用 `Port` 字段。官方 `resolver.NewNacosResolver` 不会解析这个 metadata，导致连接端口错误。

### 双模式配置

```yaml
kitex:
  client:
    resolver:
      enabled: true
      type: agnacos                    # agnacos（自定义）或 nacos（官方）
      nacos:
        group: DEFAULT_GROUP
        cluster: DEFAULT
```

## Server 端注册信息增强

在 `KitexServerSuiteBuilder.optionsFromConfig()` 中，服务端注册时也做了 Spring gRPC 兼容：

```go
// server.go:165-188
regInfo := &kregistry.Info{
    Tags: map[string]string{},
}
regInfo.Weight = 1                                  // 与 Spring gRPC 默认权重一致
regInfo.Tags["gRPC_port"] = fmt.Sprintf("%d", port) // 写入 gRPC 端口到 metadata
```

这样注册的服务能被 `AgNacosResolver` 正确解析。

## 端到端流程

```
Server 注册：
    kitex 服务 (protobuf 定义)
        │
    KitexServerSuiteBuilder.optionsFromConfig()
        │
    regInfo.Weight = 1
    regInfo.Tags["gRPC_port"] = port
        │
    Nacos Registry ────► Nacos
                           │
                          ├── instance.Port = http_port
                          └── metadata.gRPC_port = grpc_port

Client 发现：
    AgNacosResolver.Resolve("service-name")
        │
    Nacos SelectInstances
        │
    resolverInstance(in)
        │
    检查 metadata["preserved.register.source"] == "SPRING_CLOUD"
        │
    是 → 用 metadata["gRPC_port"] 替代 in.Port
    否 → 使用 in.Port
        │
    discovery.Instance("tcp", "ip:grpc_port", weight, metadata)
```
