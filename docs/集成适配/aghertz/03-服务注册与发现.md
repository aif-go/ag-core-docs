# 服务注册与发现

> 路径：`server/registry/` + `client/discovery/` | 基于 Nacos

## 概述

AgHertz 的服务注册与发现均基于 Nacos，通过 Hertz 官方 contrib 包 [hertz-contrib/registry/nacos](https://github.com/hertz-contrib/registry) 实现。

```
服务端启动 ──► Nacos Registry ──► 注册服务信息
                                       │
客户端请求 ──► Nacos Resolver ──► 获取可用实例列表
                                       │
                                 服务发现中间件 sd.Discovery
                                       │
                                 负载均衡 → 发送请求
```

## 服务注册（Server 端）

### 层次

```
server/registry/
├── zfx_registy.go      ← FX 聚合（nacos + 预留 TODO）
└── nacos/
    ├── registy.go      ← NewRegisty（创建 registry.Registry）
    └── zfx_nacos.go    ← FX Module（FxNacosRegistyModule）
```

### Nacos Registry 配置

```go
// registry/nacos/registy.go:15-24
const HertzServerRegistryPropertiesPrefix = "hertz.server.registry"

type Properties struct {
    Cluster string `value:"${cluster:DEFAULT}"`      // 集群名
    Group   string `value:"${group:DEFAULT_GROUP}"`  // 分组名
}
```

配置示例：
```yaml
hertz:
  server:
    registry:
      cluster: DEFAULT
      group: DEFAULT_GROUP
```

### 创建 Registry

```go
// registry/nacos/registy.go:30-39
func NewRegisty(param *Param, props *Properties) registry.Registry {
    return rnacos.NewNacosRegistry(
        param.NamingClient,
        rnacos.WithRegistryCluster(props.Cluster),
        rnacos.WithRegistryGroup(props.Group),
    )
}
```

依赖 `naming_client.INamingClient`（由外部 Nacos 模块提供）。

### FX 模块

```go
// registry/nacos/zfx_nacos.go:14-20
var FxNacosRegistyModule = fx.Module("fx_hertz_registry_nacos",
    fx.Provide(
        NewProperties,   // 配置
        NewParam,        // 参数（INamingClient）
        NewRegisty,      // registry.Registry
    ),
)
```

## 服务发现（Client 端）

### 层次

```
client/discovery/
├── discovery.go            ← 占位（预留多注册中心支持）
├── zfx_discovery.go        ← FX 聚合（nacos）
└── nacos/
    ├── discovery_nacos.go  ← NewResolver（创建 discovery.Resolver）
    └── zfx_nacos.go        ← FX Module（FxNacosResolverModule）
```

### Nacos Resolver 配置

```go
// discovery/nacos/discovery_nacos.go:16-31
const HertzClientPropertiesPrefix = "hertz.client.discovery"

type Properties struct {
    Enabled bool            // 是否启用，默认 true
    Type    string          // 类型，默认 "nacos"
    Nacos   NacosProperties
}

type NacosProperties struct {
    Cluster string          // 集群名
    Group   string          // 分组名
}
```

配置示例：
```yaml
hertz:
  client:
    discovery:
      enabled: true
      type: nacos
      nacos:
        cluster: DEFAULT
        group: DEFAULT_GROUP
```

### 创建 Resolver

```go
// discovery/nacos/discovery_nacos.go:39-56
func NewResolver(param *Param, props *Properties) discovery.Resolver {
    if !props.Enabled { return nil }
    if props.Type != "nacos" { return nil }
    return rnacos.NewNacosResolver(
        param.NamingClient,
        rnacos.WithResolverCluster(props.Nacos.Cluster),
        rnacos.WithResolverGroup(props.Nacos.Group),
    )
}
```

支持开关控制，未启用或非 Nacos 类型时返回 nil（不开启服务发现）。

### FX 模块

```go
// discovery/nacos/zfx_nacos.go:14-20
var FxNacosResolverModule = fx.Module("fx_hertz_resolver_nacos",
    fx.Provide(
        NewProperties,   // 配置
        NewParam,        // 参数（INamingClient）
        NewResolver,     // discovery.Resolver
    ),
)
```

## 与客户端集成

Resolver 通过 `HertzClientParams` 传入 `NewHertzClient`，在客户端创建时自动转换为服务发现中间件：

```go
// client/client.go:43-48
if params.Resolver != nil {
    cliMws = append(cliMws, &SimplePrioritizedClientMiddleware{
        Order:      ClientMiddlewarePriorityNormal,
        Middleware: sd.Discovery(params.Resolver),
    })
}
```

`sdsd.Discovery` 是 Hertz 内置的服务发现中间件，它拦截 HTTP 请求，将请求中的服务名解析为实际 IP:Port。

## 配置汇总

### Server 注册
```yaml
hertz:
  server:
    serviceName: my-service       # 注册的服务名
    tags:                          # 自定义标签
      version: v1.0
    registry:
      cluster: DEFAULT
      group: DEFAULT_GROUP
```

### Client 发现
```yaml
hertz:
  client:
    discovery:
      enabled: true                # 启用服务发现
      type: nacos
      nacos:
        cluster: DEFAULT
        group: DEFAULT_GROUP
```
