# 服务端

> 路径：`server/`

AgHertz 服务端基于 Hertz 的 `server.Hertz`，围绕 ServerConfigurator 进行封装，提供 ConfigSuite（原生 Option）和 ServerSuite（增强能力）两套配置体系。

## 文件列表

| 文件 | 职责 |
|------|------|
| `hertz.go` | NewHertzServer + HertzServerConfigParam + 配置构建 |
| `ag_server.go` | AgHertzServer（ag_server.Server 实现） |
| `config.go` | HertzServerProperties + 配置绑定 + 注册信息构建 |
| `config_options_def.go` | ConfigSuite / SimpleSuite（Hertz 原生 config.Option） |
| `server_options.go` | ServerOption / ServerSuite（增强能力） |
| `server_options_suites.go` | WithPprof / WithH2C 等增强选项实现 |
| `server_manager.go` | ServerConfigurator（路由+中间件+选项聚合初始化） |
| `route.go` | Route 定义 |
| `consts/consts.go` | 常量 |
| `zfx_server_hertz.go` | FX Module |

## 2. 配置（`config.go`）

### HertzServerProperties

```go
// config.go:16-31
type HertzServerProperties struct {
    Host          string            // 绑定 Host，默认 "0.0.0.0"
    Port          int               // 绑定端口，默认 7000
    AdaptivePort  bool              // 是否自适应端口（端口冲突时自动找空闲端口）
    EnableIPRange string            // IP 范围过滤

    KeepAlive        bool           // 是否启用 KeepAlive，默认 true
    KeepAliveTimeout time.Duration  // KeepAlive 超时，默认 60s
    Pprof            bool           // 是否启用 pprof
    PprofPath        string         // Pprof 路径，默认 "/debug/pprof"
    EnableH2C        bool           // 是否启用 H2C

    ServiceName string            // 服务名，默认 "hertz-server"
    Tags        map[string]string // 注册标签
}
```

### 配置绑定

```go
// config.go:34-38
func NewHertzServerProperties(binder ag_conf.IBinder) (*HertzServerProperties, error) {
    p := defaultHertzServerProperties()
    err := binder.Bind(p, "hertz.server")  // 前缀：hertz.server
    return p, err
}
```

### 自适应端口

```go
// config.go:40-69
func findHertzHostPort(hconf *HertzServerProperties) (host string, port int, err error)
```

- 调用 `ip.IsHostAvailable()` 校验 Host
- `AdaptivePort=true` 时，如果端口被占用自动寻找空闲端口（通过 `ip.GetAvailablePort`）
- `AdaptivePort=false` 时，端口为 0 则报错

### 注册信息构建

```go
// config.go:71-108
func buildHertzRegInfo(props *HertzServerProperties, port int) (*registry.Info, error)
```

- 通过 `ip.NewIPRanger(props.EnableIPRange)` 获取注册 IP
- 服务名默认 `"hertz-server"`
- 固定标签：`ag_core: "All rights reserved"`, `lang_type: "Golang"`

## 3. 双 Option 体系

### ConfigSuite — Hertz 原生选项

```go
// config_options_def.go:8-10
type ConfigSuite interface {
    Options() []*config.Option
}

type SimpleSuite struct {
    opts []*config.Option
}
```

用于配置 Hertz 原生参数（Host/Port、KeepAlive、Registry）：

```go
// hertz.go:32-61 — 构建示例
opts.Add(server.WithHostPorts(hertzHostStr))
opts.Add(server.WithKeepAlive(props.KeepAlive))
opts.Add(server.WithKeepAliveTimeout(props.KeepAliveTimeout))
opts.Add(server.WithRegistry(param.Register, regInfo))  // 服务注册
```

### ServerSuite — 增强能力

```go
// server_options.go:8-15
type ServerOption struct {
    F func(h *server.Hertz) error
}

type ServerSuite interface {
    Options() []*ServerOption
}
```

用于增强能力（pprof、H2C）：

```go
// server_options_suites.go:28-39
func WithPprof(pprofUrl string) ServerOption {
    return ServerOption{F: func(h *server.Hertz) error {
        pprof.Register(h, pprofUrl)
        return nil
    }}
}

func WithH2C() ServerOption {
    return ServerOption{F: func(h *server.Hertz) error {
        h.AddProtocol("h2", factory.NewServerFactory())
        return nil
    }}
}
```

### 配置构建函数

```go
// hertz.go:32-61
func BuildHertzServerConfigOption(param *HertzServerConfigParam) (*config.Option, error)

// hertz.go:64-81
func BuildHertzServerOptions(param *HertzServerConfigParam) (*ServerOption, error)
```

一个构建 Hertz 原生选项（Address、KeepAlive、Registry），一个构建增强选项（Pprof、H2C），通过 FX 组标签注入。

## 4. ServerConfigurator（`server_manager.go`）

```go
// server_manager.go:12-18
type ServerConfigurator struct {
    Server   *server.Hertz     // Hertz 服务
    Opts     []*ServerOption   // 服务器选项（增强能力）
    Routes   []*Route          // 路由
    Mws      []Middleware      // 全局中间件（Middleware = app.HandlerFunc）
    MwsHFunc []app.HandlerFunc // 全局中间件（直接类型）
}
```

### InitHertzServer

```go
// server_manager.go:24-44
func (m *ServerConfigurator) InitHertzServer() error {
    // 1. 应用增强选项（pprof、H2C）
    m.ApplyServerOptions()
    // 2. 应用全局中间件
    m.ApplyMiddleware()
    // 3. 应用路由
    m.ApplyRoute()
}
```

**初始化顺序**（重要）：选项 → 中间件 → 路由。因为路由注册可能依赖中间件先行（如日志、鉴权）。

### Route 定义

```go
// route.go:11-15
type Route struct {
    HttpMethod   string            // GET / POST / PUT / DELETE
    RelativePath string            // /api/v1/users/:id
    Handlers     []app.HandlerFunc // handler 链
}

func NewRoute(method, path string, handlers ...app.HandlerFunc) *Route
```

## 5. 注册信息构建流程

```
HertzServerConfigParam
├── HertzServerProperties (配置)
└── Register registry.Registry (Nacos, optional)

BuildHertzServerConfigOption(param)
    │
    ├── findHertzHostPort(props)
    │   ├── Host: ip.IsHostAvailable
    │   └── Port: AdaptivePort → ip.GetAvailablePort
    │
    ├── WithKeepAlive / WithKeepAliveTimeout
    │
    └── if Register != nil:
        └── buildHertzRegInfo(props, port)
            ├── ip.NewIPRanger(EnableIPRange) → GetLocalIP
            ├── ServiceName (默认 "hertz-server")
            └── Tags (ag_core, lang_type)
            └── WithRegistry(Register, regInfo)
```

```
    ▼

```
