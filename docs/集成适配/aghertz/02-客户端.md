# 客户端

> 路径：`client/`

AgHertz 客户端基于 Hertz `*client.Client`，封装了**配置构建**、**ClientSuite 选项聚合**、**优先级中间件排序**、**服务发现集成**等能力。

## 文件列表

| 文件 | 职责 |
|------|------|
| `client.go` | HertzClientParams + NewHertzClient |
| `config.go` | HertzClientProperties + 配置绑定 + 选项构建 |
| `options.go` | ClientSuite / SimpleClientSuite + WithClientSuite |
| `middleware.go` | 优先级中间件：PrioritizedClientMiddleware + 排序 |
| `zfx_client_hertz.go` | FX Module |

## 2. ClientSuite — 选项聚合

```go
// options.go:8-16
type ClientSuite interface {
    Options() []*config.ClientOption
}

type SimpleClientSuite struct {
    opts []*config.ClientOption
}
```

与 Server 端的 `ConfigSuite` 对称，用于聚合多个 Hertz 原生的 `config.ClientOption`：

```go
// options.go:35-47
func WithClientSuite(suite ClientSuite) config.ClientOption {
    return config.ClientOption{F: func(o *config.ClientOptions) {
        opts := []config.ClientOption{}
        for _, opt := range suite.Options() {
            opts = append(opts, *opt)
        }
        o.Apply(opts)
    }}
}
```

## 3. 优先级中间件 (`middleware.go`)

### 优先级常量

```go
// middleware.go:11-16
const (
    ClientMiddlewarePriorityHighest = 0
    ClientMiddlewarePriorityHigh    = 1000
    ClientMiddlewarePriorityNormal  = 2000
    ClientMiddlewarePriorityLow     = 3000
    ClientMiddlewarePriorityLowest  = 4000
)
```

### 带优先级的中间件接口

```go
// middleware.go:23-29
type PrioritizedClientMiddleware interface {
    GetOrder() int               // 数值越小优先级越高
    GetMiddleware() client.Middleware
}

// middleware.go:32-35
type SimplePrioritizedClientMiddleware struct {
    Order      int
    Middleware client.Middleware
}
```

### 排序与注入

```go
// middleware.go:84-96
func SortAndApplyMiddleware(c *client.Client, prioritizedMws []PrioritizedClientMiddleware) {
    // 1. 按优先级排序（升序）
    sort.Sort(ByClientPriority(prioritizedMws))
    // 2. 按顺序应用所有中间件
    for _, pmw := range prioritizedMws {
        c.Use(pmw.GetMiddleware())
    }
}
```

排序使用 `sort.Interface` 实现。优先级值小的中间件**先执行**（Highest→High→Normal→Low→Lowest）。

### 兼容普通中间件

在 `NewHertzClient` 中，普通中间件（不带优先级）自动以 `Normal` 优先级注入：

```go
// client.go:57-66
if len(params.ClientMiddleware) > 0 {
    for _, mw := range params.ClientMiddleware {
        cliMws = append(cliMws, &SimplePrioritizedClientMiddleware{
            Order:      ClientMiddlewarePriorityNormal,
            Middleware: mw,
        })
    }
}
```

## 4. NewHertzClient (`client.go`)

### HertzClientParams

```go
// client.go:13-24
type HertzClientParams struct {
    ClientProperties                 *HertzClientProperties
    ClientOptions                    []*config.ClientOption
    ClientMiddleware                 []client.Middleware        // 普通中间件（不保证顺序）
    PrioritizedClientMiddleware      []PrioritizedClientMiddleware // 带优先级的中间件
    PrioritizedClientMiddlewareSuite PrioritizedClientMiddlewareSuite
    Resolver                         discovery.Resolver         // 服务发现
}
```

### 创建流程

```go
// client.go:27-77
func NewHertzClient(params *HertzClientParams) (*client.Client, error)
```

1. **应用客户端选项** → 将 `ClientOptions` 聚合到 `ClientSuite`，创建 `*client.Client`
2. **构建中间件列表**（按注入顺序）：
   - `Resolver` → 转换为服务发现中间件 `sd.Discovery(params.Resolver)`，优先级 Normal
   - `PrioritizedClientMiddleware` → 保持原有优先级
   - `ClientMiddleware`（普通）→ 统一转换为 Normal 优先级
   - `PrioritizedClientMiddlewareSuite` → 展开并入
3. **排序并应用** → `SortAndApplyMiddleware(c, cliMws)`

**中间件优先级顺序**（最终执行链）：
```
Highest (0)
  → Metadata Middleware (元数据透传)
High (1000)
  → ...
Normal (2000)
  → sd.Discovery (服务发现)
  → 普通中间件
Low (3000)
Lowest (4000)
```
