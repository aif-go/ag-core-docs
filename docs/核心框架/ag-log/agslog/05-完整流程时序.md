# 完整流程时序

本章将 agslog 的完整生命周期以时序图形式呈现，涵盖从 `init()` 到运行时调用的所有关键路径。

## 时序图

```
时间 →
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ① init()
     │
     ├─ newBuilder()           → Builder(空)
     │
     ├─ GetSlogByName("agslog_top")
     │    ├─ namedLogger miss
     │    ├─ getNamedHandler miss → resolveHandler fail → nil
     │    ├─ handler==nil, hname==topLoggerName → slog.Default()
     │    ├─ 创建 ReplaceableHandler("agslog_top", slog.Default().Handler())
     │    ├─ 不存入 replaceableHandllers（因为 hname == topLoggerName）
     │    └─ 创建 slog.Logger, 存入 namedLogger
     │
     ├─ topLogger.Store(logger)   → TopLogger 可用
     └─ builder.Store(builder)    → DefaultBuilder 可用
│
│  状态：TopLogger → ReplaceableHandler("agslog_top") → text handler (stderr)
│      ：Builder → 空（全字段零值）
│
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ② FX 配置注入（或手动配置）
     │
     ├─ BindAgSlogProperties     → props = {IsDefault, TopHandler}
     ├─ 注册 Handler 工厂
     │    ├─ fanout.NewFanoutHandlerFactorys  → factories 追加
     │    └─ async.BuildAsyncHandlerFactorys  → factories 追加
     ├─ 注册 Handler
     │    └─ slogzap.NewSlogHandler4ZapProps → handlersCaches 追加
     │
     └─ FxBuildAgSlogBuilder(params)
          ├─ WithProperties(props)
          ├─ AddHandlerss(zap handlers)
          ├─ AddHandlerFactoryss(fanout factories)
          ├─ AddHandlerFactoryss(async factories)
          └─ AddMiddlewares(...)
│
│  状态：Builder.props = {IsDefault:false, TopHandler:["zap1"]}
│      ：Builder.factories = [fanout工厂, async工厂]
│      ：Builder.handlersCaches = [zap1→zap_handler, zap2→zap_handler]
│
│  ⚠️ 注意：此时 TopLogger 仍处于占位状态
│
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ③ 可选：Build 前调用 GetSlogByName("f1")
     │
     ├─ namedLogger["f1"] miss
     ├─ getNamedHandler("f1")
     │    ├─ handlers["f1"] miss
     │    ├─ resolveHandler("f1")
     │    │    ├─ handlersCaches["f1"] miss
     │    │    └─ factories 遍历 → 匹配 fanout factory["f1"]
     │    │         └─ GetHandler(resolveHandler)
     │    │              └─ DoGetHandler → resolveHandler("zap1")
     │    │                   ├─ handlersCaches["zap1"] 命中 → zap1 handler
     │    │                   └─ 返回
     │    ├─ 应用中间件（无）
     │    └─ wrapNamedHandlerIfNeed("f1", fanout_handler)
     │         → NamedHandler("f1", fanout(zap1Handler))
     │
     ├─ handler不为 nil，无需降级
     ├─ 创建 ReplaceableHandler("f1", NamedHandler("f1", ...))
     ├─ 存入 replaceableHandllers["f1"]
     ├─ 创建 slog.New(handler), 存入 namedLogger["f1"]
     └─ 返回 Logger
│
│  状态：logger_f1 → ReplaceableHandler("f1") → NamedHandler("f1") → Fanout(zap1, zap2)
│      ：replaceableHandllers = {"f1": ReplaceableHandler("f1")}
│
│  此时 logger_f1.Info("msg") → 通过 Fanout → zap1 + zap2 ✅
│  实际上在 Build 之前，fanout 和 zap 已经可以工作！
│
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ④ FxBuildTopLog(builder) → builder.Build()
     │
     ├── initTopLogger()
     │    │
     │    ├── resolveTopHandlers()
     │    │    ├─ custTopHandlers: 空
     │    │    └─ props.TopHandler: ["zap1"]
     │    │         └─ resolveHandler("zap1")
     │    │              └─ handlersCaches["zap1"] 命中 → zap1 handler ✅
     │    ├─ topHandlers = [zap1 handler]
     │    ├─ 单 handler → 不用 fanout
     │    ├─ 中间件检查（无）
     │    ├─ wrapNamedHandlerIfNeed("agslog_top", zap1_handler)
     │    │    → NamedHandler("agslog_top", zap1_handler)
     │    │
     │    ├─ TopLogger().Handler() 获取旧 handler
     │    │    → ReplaceableHandler("agslog_top", slog.Default().Handler())
     │    ├─ IsMatchesName()? 检查旧 handler 的名称
     │    │    → 旧 handler 是 slog.Default().Handler()，不是 INamedHandler → false
     │    ├─ th.ReplaceHandler(rhandler) ← ★ 原子替换！
     │    │    → ReplaceableHandler("agslog_top") 内部指针现在指向
     │    │      NamedHandler("agslog_top", zap1_handler)
     │    │
     │    └─ IsDefault=false → 不调用 slog.SetDefault
     │
     └── tryReplaceNamedHandler()
          │
          ├─ 遍历 replaceableHandllers
          │    └─ key="f1", value=ReplaceableHandler("f1")
          │         ├─ rh.IsMatchesName()?
          │         │   内部 handler 当前是 NamedHandler("f1", fanout(zap1))
          │         │   名称 "f1" == rh.name "f1" → true ✅
          │         └─ 跳过（已匹配）
          │
          └─ 没有其他条目，结束
│
│  状态：TopLogger → ReplaceableHandler("agslog_top")
│                      → NamedHandler("agslog_top")
│                        → zap1 handler ✅
│      ：logger_f1 不变，其 handler 本来就是正确的
│
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ⑤ 运行时：TopLogger().Info("hello")
     │
     ├─ slog.Logger.Handle()
     ├─ ReplaceableHandler("agslog_top").Handle(ctx, record)
     │    └─ (*rh.handler.Load()).Handle(...)  ← atomic load
     │         └─ NamedHandler("agslog_top").Handle(...)
     │              ├─ 写入 Context(HandlerStartCtxKey, "agslog_top")
     │              └─ zap1 handler.Handle(...)
     │                   └─ 写入文件/控制台
     └─ Hello 记录已输出 ✅
│
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ⑥ 运行时：GetSlogByName("f1").Info("msg")
     │
     ├─ namedLogger["f1"] 命中 → 直接返回缓存的 Logger
     ├─ 原地调用 Handle
     ├─ ReplaceableHandler("f1") → NamedHandler("f1")
     │    → Fanout(zap1, zap2)
     └─ 同时写入两个输出 ✅
```

## 关键路径总结

### 路径 A：Build 前 GetSlogByName（④之前）

```
GetSlogByName(name)
  ├─ namedLogger miss → DCLP
  ├─ getNamedHandler(name)
  │    └─ resolveHandler(name)
  │         ├─ handlersCaches 命中 → 返回
  │         └─ factories 命中 → 递归解析 → 返回
  ├─ (不为 nil) → 正常流程
  ├─ NewReplaceableHandler(name, handler)
  ├─ 存入 replaceableHandllers
  └─ 返回 Logger
```

### 路径 B：Build 后 GetSlogByName（④之后首次）

```
GetSlogByName(name)
  ├─ namedLogger miss → DCLP
  ├─ getNamedHandler(name)
  │    └─ handlers 缓存 miss
  │    └─ resolveHandler(name)
  │         └─ handlersCaches 命中（被 Build 或之前解析填充）
  │    └─ 应用中间件
  │    └─ wrapNamedHandlerIfNeed
  │    └─ 存入 handlers
  ├─ NewReplaceableHandler(name, handler)
  ├─ 存入 replaceableHandllers（但 tryReplaceNamedHandler 已过，下次 Build 才替换）
  └─ 返回 Logger（handler 已经正确）
```

### 路径 C：Build 后再次 GetSlogByName（④之后再次）

```
GetSlogByName(name)
  ├─ namedLogger 命中 → 直接返回 ✅
  └─ 零开销
```

### 路径 D：TopLogger 的热替换（④中）

```
initTopLogger()
  ├─ 构建新 handler 链
  ├─ TopLogger().Handler() → 获取旧 ReplaceableHandler
  ├─ th.ReplaceHandler(newHandler) → atomic.Pointer.Store
  └─ 后续所有 TopLogger().Info() 调用立即使用新 handler
```

## 异常路径分析

### 异常 1：Build 时 resolveTopHandler 找不到

```
resolveTopHandlers()
  ├─ props.TopHandler = ["unknownHandler"]
  ├─ resolveHandler("unknownHandler") → ❌ handlersCaches miss, factories miss
  ├─ 打印错误 "agslog[error]: resolveHandler[unknownHandler] fail:..."
  └─ continue（跳过，不中断）
```

→ 顶层无 handler → `initTopLogger` 返回当前的占位 TopLogger（相当于什么都没做）

### 异常 2：Factory 循环依赖

```
f1: ["f2"], f2: ["f1"]
resolveHandler("f1")
  → f1.TryLock ✅
  → f1.DoGetHandler → resolveHandler("f2")
    → f2.TryLock ✅
    → f2.DoGetHandler → resolveHandler("f1")
      → f1.TryLock ❌ → "maybe circular call"
```

→ 错误传播到 `initTopLogger` → `resolveTopHandlers` 跳过 → 返回占位 TopLogger

### 异常 3：tryReplaceNamedHandler 解析失败

```
tryReplaceNamedHandler
  ├─ replaceableHandllers["f1"]
  ├─ resolveHandler("f1") → ❌（factory 被移除或不存在）
  └─ h = TopLogger().Handler()
      → ReplaceableHandler("f1") 被替换为 TopLogger 的 handler
      → f1 的日志现在走 TopLogger 的输出
```

→ 静默降级，不 panic
