# 🧱 核心框架 — ag/

ag-core 的核心框架层，位于 `ag/` 目录。提供微服务运行所需的基础设施。

## 模块一览

| **模块** | **包路径** | **说明** |
|----------|-----------|------|
| [App 应用启动器](ag-app/00-AgApp.md) | `ag/ag_app/` | 统一入口，管理服务器生命周期 |
| [AgConf 配置管理](ag-conf/00-AgConf-概览.md) | `ag/ag_conf/` | 多属性源、占位符解析、绑定、热更新、解密 |
| [AgServer 服务端抽象](ag-server/00-AgServer.md) | `ag/ag_server/` | Gin/HTTP 服务端封装 |
| [AgService 服务注册](ag-service/00-AgService.md) | `ag/ag_service/` | 服务注册与发现抽象 |
| [AgCrypto 加密](ag-crypto/00-AgCrypto.md) | `ag/ag_crypto/` | AES/RSA 等加解密工具 |
| [AgCommon 公共工具](ag-common/00-AgCommon.md) | `ag/ag_common/` | 切片、字符串等通用工具 |
| [AgExt 扩展](ag-ext/00-AgExt.md) | `ag/ag_ext/` | 可插拔扩展接口 |
| [AgLog 日志](ag-log/00-AgLog.md) | `ag/ag_log/` | 日志封装 |

## 调用关系

```
App.Start()
  ├── 加载配置 (AgConf)
  ├── 初始化服务器 (AgServer)
  ├── 注册服务 (AgService)
  ├── 应用扩展 (AgExt)
  └── 启动监听
```

## 关键设计

- 采用 **Options 模式**（`WithXXX()` 函数）进行配置
- 模块间通过 **接口依赖**，而非具体类型
- 支持 **多配置文件合并**（主配置 + 环境特定配置）
- 属性占位符支持 `${...}` 和 `{{...}}` 两种语法
