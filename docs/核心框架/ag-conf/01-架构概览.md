# AgConf 架构概览

> 深度借鉴 Spring Framework 的 `Environment` + `PropertySource` + `PropertyResolver` 体系

## 类层次结构

```
IPropertySource                    ← 单个属性源（map[string]any）
  └── MapPropertySource
       ├── PropertiesPropertySource           ← 带互斥锁
       └── SystemEnvironmentPropertySource    ← 系统环境变量

IPropertySources                   ← 属性源集合
  └── MutablePropertySources       ← 可变的、有序的、并发安全的集合

IPropertyResolver                  ← 属性解析
  └── IConfigurablePeopertyResolver          ← 可配置（前缀/后缀/分隔符）
       └── AbstractPropertyResolver           ← 抽象实现 + 占位符
            └── PropertySourcesPropertyResolver  ← 具体实现

IEnvironment                       ← 环境（已废弃）
  └── IConfigurableEnvironment     ← 可配置环境
       └── AbstractEnvironment     ← 委托给 PropertyResolver
            └── StandardEnvironment           ← 默认实现
```

## 数据流

```
GetProperty("db.url")
     │
     ▼
StandardEnvironment.GetProperty("db.url")
     │  委托给
     ▼
PropertySourcesPropertyResolver.getProperty("db.url")
     │
     ▼
遍历 MutablePropertySources（按优先级）
     │
     ├── [DECRYPT]-SystemEnvAndProp    (最高优先级 - 解密后的系统配置)
     ├── [DECRYPT]-[LOCAL]             (解密后的本地配置)
     ├── [LOCAL]-app.yml               (本地配置文件)
     ├── [SYS]-Properties              (命令行 -D 参数)
     └── [SYS]-Environment             (系统环境变量 - 最低优先级)
     │
     ▼ 找到值后
     ▼
PropertySourcesPropertyResolver.ResolveNestedPlaceholders(value)
     │
     ▼
PropertyPlaceholderHelper.parseStringValueWithVisited()
     │  递归解析 ${...} 占位符
     ▼
最终值
```

## 属性源优先级

```
高优先级
   │
   ├── [DECRYPT]-*              ← 解密后的配置（最高）
   ├── Nacos 配置               ← 远程配置中心
   ├── [LOCAL]-app.yml          ← 本地 YAML 文件
   ├── [SYS]-Properties         ← 命令行 -D 参数
   └── [SYS]-Environment        ← 系统环境变量（最低）
   │
低优先级
```

**覆盖规则：** 高优先级的属性源中的值会覆盖低优先级中的同名值。

## 关键设计要点

1. **全委托模式** — `AbstractEnvironment` 将所有属性操作委托给内部的 `PropertyResolver`，本身只管理属性源集合
2. **大小写不敏感** — 所有 key 查找使用 `strings.EqualFold`，不区分大小写
3. **`_` 转 `.`** — 环境变量中的 `_` 会被自动替换为 `.`，如 `DB_URL` → `db.url`
4. **懒加载占位符解析器** — `PropertyPlaceholderHelper` 使用 `sync.Once` 延迟初始化
5. **池化 StringBuilder** — 占位符解析使用 `sync.Pool` 复用 strings.Builder
6. **CopyOnWrite 切片** — 属性源列表使用 `ag_ext.CopyOnWriteSlice` 实现并发安全
