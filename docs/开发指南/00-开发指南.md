## 开发流程

```
1. 定义表结构 → Excel 模板或 MySQL DDL
2. 生成代码 → gen-go-db / aggo
3. 编写业务逻辑 → 在生成的 DAO 上封装 Service
4. 注册 API → .proto 定义 → aggo 生成桩代码
5. 启动服务 → App.Start()
```
