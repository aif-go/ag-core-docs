# 使用指南

> 面向业务开发者：从 Excel 模板到完整的 Model + DAO 代码

## 快速开始

### 1. 准备 Excel 模板

创建一个 Excel 文件，按以下格式填写表结构。每个 sheet 对应一张数据库表。

**sheet 名称**：表名（如 `TM_USER`）

**第 1 行** — 表名声明

| 表名 | |
|------|------|
| `表名` | `TM_USER` |

**列定义区** — 标题行标记为 `列名`

| 列名 | 类型 | 长度 | 必填 | 默认值 | 自增 | 支持更新 | 描述 | Tag |
|------|------|------|------|--------|------|---------|------|-----|
| SEQ | int64 | | Y | | Y | N | 序列号 | |
| NAME | string | 30 | Y | | N | Y | 姓名 | |
| SEX | int | | N | 1 | N | Y | 1-男 2-女 | |
| ADDRESS | string | 100 | Y | | N | Y | 地址 | |
| PHONE | string | 11 | N | | N | Y | 手机 | |
| CREATED_TIME | time | | N | | N | N | 创建时间 | `///@create` |
| LAST_MODIFIED_TIME | time | | N | | N | N | 更新时间 | `///@update` |

**主键区** — 标题行标记为 `主键`

| | |
|--------|------|
| `PRIMARY_KEY` | `SEQ` |

**索引区** — 标题行标记为 `索引`

| | | |
|--------|------|------|
| `INDEX1_TM_USER` | `NAME` | `ADDRESS` |

**约束区** — 标题行标记为 `约束`

| | |
|--------|------|
| `TM_USER_UNIQUE_1` | `PHONE` |

### 2. 生成 YAML 定义

```bash
gen-go-db yaml -i ./TM_USER.xlsx -o ./
```

输出：`./repository/yaml/TM_USER.yaml`

### 3. 生成 Go 代码

```bash
gen-go-db db -i ./repository/yaml -o ./
```

输出 5 个文件：

```
repository/
├── model/
│   └── tm_user_model.go         ← Model 定义（结构体、方法）
└── dao/
    ├── tm_user_dao.go            ← DAO CRUD（增删改查）
    ├── tm_user_constant.go       ← 常量定义
    ├── tm_user_namingsql.go      ← 命名 SQL
    ├── mysql_tm_user_namingsql.go  ← MySQL SQL
    └── db2_tm_user_namingsql.go    ← DB2 SQL
```

### 4. 在项目中引用

```go
package service

import (
    "context"
    "gitlab.allinfinance.com/your-project/repository/dao"
    "gitlab.allinfinance.com/your-project/repository/model"
)

func GetUser(ctx context.Context, seq int64) (*model.TmUser, error) {
    entity := &model.TmUser{Seq: seq}
    ok, err := dao.TmUserDao.Get(ctx, entity)
    if err != nil {
        return nil, err
    }
    if !ok {
        return nil, nil
    }
    return entity, nil
}
```

## 完整使用流程

```bash
# 1. Excel → YAML
gen-go-db yaml -i ./模型模板.xlsx -o ./

# 2. 检查生成的 YAML
cat ./repository/yaml/TM_USER.yaml

# 3. YAML → Model + DAO
gen-go-db db -i ./repository/yaml -o ./

# 4. 在代码中使用生成的 DAO
```

## 常用命令

### 只生成特定表

```bash
gen-go-db yaml -i ./模型模板.xlsx -o ./ -T TM_USER,TM_ORDER
gen-go-db db -i ./repository/yaml -o ./ -T TM_USER
```

### 指定数据库类型

```bash
# 只生成 MySQL 类型的 DAO
gen-go-db db -i ./repository/yaml/TM_USER.yaml -o ./ -d mysql

# 只生成 DB2 类型
gen-go-db db -i ./repository/yaml/TM_USER.yaml -o ./ -d db2
```

### 指定模块名

```bash
gen-go-db db -i ./repository/yaml -o ./ -m gitlab.allinfinance.com/your-project
```

### 测试模式

```bash
# 生成示例 YAML 了解格式
gen-go-db yaml -t
```

## 自定义查询

在 Excel 中定义自定义查询，生成的 DAO 会自动包含对应的命名 SQL。

### 简单条件查询

在 `{表名}@` sheet 的**普通模式**下填写：

| 方法名 | 查询字段 | 排序 | 条件 | SQL 参数 | 分页 |
|--------|---------|------|------|---------|------|
| FindByName | NAME,ADDRESS | | NAME = @Name | | Y |
| FindByPhone | * | | PHONE = @Phone | | N |

生成的用法：

```go
// 条件查询（分页）
result, err := dao.TmUserDao.FindByName(ctx, &model.TmUserFindByNameArg{
    Name: "张三",
})

// 无条件查询
result, err := dao.TmUserDao.FindAll(ctx)
```

### 动态 SQL 模板

在 `{表名}@` sheet 中首行标记 `动态模版`，然后定义：

| 方法名 | 查询字段 | SQL 模板 | 参数定义 | 排序 | 分页 |
|--------|---------|---------|---------|------|------|
| QueryByCondition | * | `SELECT * FROM TM_USER WHERE NAME = @Name AND AGE > @Age` | `Name,string,N;Age,int,N` | | Y |

- `@Name`、`@Age` 为参数占位符
- 参数定义格式：`属性名,类型,是否切片(Y/N)`，分号分隔
- 未定义的参数自动从列名驼峰匹配类型

> **注意**：动态 SQL 模板中不允许出现 `1 = 1` 条件。

## Tag 标记

在 Excel 的 Tag 列中填写特殊标记来控制代码生成行为：

| Tag | 效果 |
|-----|------|
| `///@create` | 标记为自动创建时间字段，生成 `AUTOCREATETIME` GORM 标签 |
| `///@update` | 标记为自动更新时间字段，生成 `AUTOUPDATETIME` GORM 标签 |
| `///@javaVersion` | 标记为乐观锁字段 |
| `///@omitempty` | 零值时忽略该字段（仅用于特定场景） |

## 索引命中检查

生成 DAO 前工具会自动验证每个自定义查询的 WHERE 条件是否包含索引列或主键列。如果查询条件**没有命中任何索引**，生成会失败并提示。

```bash
# 错误示例
查询 FindByAddress 的请求参数没有命中任何索引或主键
```

解决方法：确保 WHERE 条件中的字段至少有一个是**主键**或**索引的第一列**。

## 最佳实践

1. **Excel 模板管理** — 将 Excel 模板纳入版本管理，作为表结构设计的唯一源头
2. **表名命名** — 使用大写字母 + 下划线命名（如 `TM_USER`），自动转换为大驼峰结构体名
3. **自定义查询** — 优先使用简单条件模式，仅在复杂 SQL（多表 JOIN、聚合函数）时使用动态模板
4. **索引设计** — 自定义查询的 WHERE 条件字段应设计对应的数据库索引
5. **增量生成** — Model 文件中的 `internal/service/*.go` 业务文件不会覆盖，可放心重复运行

## 常见问题

**Q: 生成的代码在哪个目录？**
A: `repository/model/` 和 `repository/dao/` 下。

**Q: 如何只更新一张表？**
A: 使用 `-T` 参数指定表名。

**Q: 生成了不需要的文件怎么删除？**
A: 手动删除对应表的文件即可，后续重新生成不会创建已被删除的表。

**Q: 索引安全检查太严格了怎么办？**
A: 在 Excel 中为查询字段添加对应的数据库索引，或在查询条件中增加主键/索引列的条件。
