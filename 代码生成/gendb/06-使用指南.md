# 使用指南

> 面向业务开发者：从 Excel 模板到完整的 Model + DAO 代码

## 完整流程

```bash
# 1. 准备 Excel 模板（每个 sheet 对应一张表）
#    详见 [[08-Excel模板规范|Excel 模板规范]]

# 2. Excel → YAML
gen-go-db yaml -i ./模型模板.xlsx -o ./

# 3. 检查生成的 YAML
cat ./repository/yaml/TM_USER.yaml

# 4. YAML → Model + DAO
gen-go-db db -i ./repository/yaml -o ./ -m your.project.module

# 5. 在代码中使用生成的 DAO
```

> 各命令的详细参数见 [[../../CLI工具/gen-go-db/00-GenGoDb|CLI 工具文档]]。
> 生成的 DAO 的详细使用教程见 [[../../集成适配/agdb/07-生成DAO使用指南|生成 DAO 使用指南]]。

## 使用生成的 DAO

```go
package service

import (
    "context"
    "gitlab.allinfinance.com/your-project/repository/dao"
    "gitlab.allinfinance.com/your-project/repository/model"
)

func GetUser(ctx context.Context, seq int64) (*model.TmUser, error) {
    student, err := dao.StudentDao.FindByPrimaryKey(ctx, model.StudentPrimaryKey(seq))
    if err != nil {
        return nil, err
    }
    return student, nil
}
```

### CRUD 示例

```go
dao := NewStudentDao(repository, baseDao)

// 1. 插入
affected, err := dao.InsertOne(ctx, &model.Student{
    Name: "张三",
    Age:  18,
})

// 2. 按主键查询
student, err := dao.FindByPrimaryKey(ctx, model.StudentPrimaryKey(1))

// 3. 自定义查询（命名 SQL）
result, err := dao.FindByCustomerRule(ctx, FindByAgeNamingInfo,
    &model.StudentFindByAgeArg{}.WithAge(18).WithStuno(1001))

// 4. 条件查询（构造器模式）
condition := conditonwhere.NewWhereClauseBuilder()
condition.And("AGE = ?", 18)
list, page, err := dao.FindByCondition(ctx, condition, nil, &db.Page{PageNum: 1, PageSize: 10})
```

## 生成产物结构

详见 [[07-DAO生成产物详解|DAO 生成产物详解]] 了解每个文件的详细代码结构。

```
repository/
├── model/
│   └── {table}_model.go              ← 结构体 + 方法 + 查询参数
└── dao/
    ├── {table}_dao.go                ← CRUD + 命名 SQL
    ├── {table}_constant.go           ← 常量
    ├── {table}_namingsql.go          ← 命名 SQL 初始化
    ├── mysql_{table}_namingsql.go    ← MySQL SQL
    └── db2_{table}_namingsql.go      ← DB2 SQL
```

## 自定义查询

在 Excel 中定义自定义查询，生成的 DAO 会自动包含对应的命名 SQL。

### 简单条件查询

在 `{表名}@` sheet 的**普通模式**下填写：

| 方法名 | 查询字段 | 排序 | 条件 | SQL 参数 | 分页 |
|--------|---------|------|------|---------|------|
| FindByName | NAME,ADDRESS | | NAME = @Name | | Y |
| FindByPhone | * | | PHONE = @Phone | | N |

生成的用法：

```go
result, err := dao.TmUserDao.FindByName(ctx, &model.TmUserFindByNameArg{
    Name: "张三",
})
```

### 动态 SQL 模板

在 `{表名}@` sheet 中首行标记 `动态模版`：

| 方法名 | 查询字段 | SQL 模板 | 参数定义 | 排序 | 分页 |
|--------|---------|---------|---------|------|------|
| QueryByCondition | * | `SELECT * FROM TM_USER WHERE NAME = @Name AND AGE > @Age` | `Name,string,N;Age,int,N` | | Y |

> **注意**：动态 SQL 模板中不允许出现 `1 = 1` 条件。

## 常用命令

```bash
# 只生成特定表
gen-go-db yaml -i ./模型模板.xlsx -o ./ -T TM_USER,TM_ORDER
gen-go-db db -i ./repository/yaml -o ./ -T TM_USER

# 指定数据库类型
gen-go-db db -i ./repository/yaml/TM_USER.yaml -o ./ -d mysql

# 指定模块名
gen-go-db db -i ./repository/yaml -o ./ -m gitlab.allinfinance.com/your-project

# 测试模式（查看 YAML 示例格式）
gen-go-db yaml -t
```

## 索引命中检查

生成 DAO 前工具会自动验证每个自定义查询的 WHERE 条件是否包含索引列或主键列。如果查询条件**没有命中任何索引**，生成会失败并提示。

```bash
# 错误示例
查询 FindByAddress 的请求参数没有命中任何索引或主键
```

解决方法：确保 WHERE 条件中的字段至少有一个是**主键**或**索引的第一列**。

## 最佳实践

1. **Excel 模板管理** — 将 Excel 模板纳入版本管理，作为表结构设计的唯一源头
2. **表名命名** — 使用大写字母 + 下划线命名（如 `TM_USER`），自动转换为大驼峰结构体名
3. **自定义查询** — 优先使用简单条件模式，仅在复杂 SQL（多表 JOIN、聚合函数）时使用动态模板
4. **索引设计** — 自定义查询的 WHERE 条件字段应设计对应的数据库索引
5. **增量生成** — 重复运行 `gen-go-db db` 不会覆盖业务代码，可放心执行

## 常见问题

**Q: 生成的代码在哪个目录？**
A: `repository/model/` 和 `repository/dao/` 下。详见 [[07-DAO生成产物详解|DAO 生成产物详解]]。

**Q: 如何只更新一张表？**
A: 使用 `-T` 参数指定表名。

**Q: 生成了不需要的文件怎么删除？**
A: 手动删除对应表的文件即可，后续重新生成不会创建已被删除的表。

**Q: 索引安全检查太严格了怎么办？**
A: 在 Excel 中为查询字段添加对应的数据库索引，或在查询条件中增加主键/索引列的条件。
