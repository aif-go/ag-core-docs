# ⚡ 代码生成流程

ag-core 最核心的价值——从简单的描述文件自动生成完整的后端代码。

## 两条主线

### 1. 数据库 → DAO 代码（Excel/MySQL → Go）

```
[输入]                         [处理]                       [输出]
──────────────────────────────────────────────────────────────────
Excel 模板  ───→  gen-go-db  ───→  YAML 定义
 表结构定义        (解析器)        DatabaseTable             ──→  Go Model
 字段说明                          Column                     ──→  DAO CRUD
 索引                              Indexes                    ──→  条件查询
                                     ↓
                              gen-go-db
                              (代码生成器)
```

### 2. Protobuf → 微服务代码（.proto → Go）

```
[输入]         [处理]                           [输出]
──────────────────────────────────────────────────────────
.proto  ───→  aggo proto            ───→  api/*.pb.go (基础类型)
文件           ├── protoc-gen-go-agapi      api/*_interface.go (接口)
              ├── protoc-gen-go-agserver    internal/adpgen/* (适配器)
              ├── protoc-gen-go-agkitex     internal/adpgen/kitex/* (Kitex)
              ├── protoc-gen-go-aghertz     internal/adpgen/hertz/* (Hertz)
              ├── protoc-gen-go-agservice   internal/service/* (业务入口)
              └── protoc-gen-openapi        openapi.yaml (API文档)
```

## 开发完整流程

```
1. aggo new -r <模板>      创建项目
2. 编写 idl/api/*.proto    定义服务接口
3. aggo proto              生成全套代码
4. 实现 internal/service/*  编写业务逻辑
5. cd cmd/server && go build && ./server
```
