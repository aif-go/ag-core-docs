# gen-go-db db 命令详解

> 功能：从 YAML 定义文件生成 Go Model + DAO + 命名 SQL 代码

## 用途

消费 `gen-go-db yaml` 生成的（或人工编写的）YAML 表定义文件，输出完整的 Go 数据库访问层代码，包括 ORM Model 结构体、DAO CRUD 方法、命名 SQL 定义以及数据库特化 SQL。

## 命令格式

```bash
gen-go-db db -i <yaml-path> -o <output-dir> [options]
```

## 参数清单

| 参数 | 缩写 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|:----:|--------|------|
| `--input` | `-i` | string | ✅ | — | YAML 文件路径或目录 |
| `--output` | `-o` | string | ✅ | — | 输出基础目录（自动拼接 `repository/model/` 和 `repository/dao/`） |
| `--table` | `-T` | string | ❌ | 全部表 | 指定表名，逗号分隔多个 |
| `--module` | `-m` | string | ❌ | 从 `go.mod` 读取 | 项目模块名，影响 import 路径 |
| `--dbtype` | `-d` | string | ❌ | mysql+db2 | 数据库类型：`mysql` / `db2` |

## 使用示例

```bash
# 基本用法：YAML 目录 → 全部表
gen-go-db db -i ./repository/yaml -o ./

# 单文件
gen-go-db db -i ./repository/yaml/TM_USER.yaml -o ./

# 指定表名
gen-go-db db -i ./repository/yaml -o ./ -T TM_USER

# 指定模块名（影响 import 路径）
gen-go-db db -i ./repository/yaml -o ./ -m gitlab.allinfinance.com/myproject

# 只生成 MySQL 类型
gen-go-db db -i ./repository/yaml -o ./ -d mysql

# 组合使用
gen-go-db db -i ./repository/yaml/TM_USER.yaml -o ./ -m myproject -d mysql -T TM_USER
```

## 输出文件详解

对于表 `TM_USER`，执行 `gen-go-db db` 后生成 5 个文件：

```
repository/
├── model/
│   └── tm_user_model.go              ← Model 定义
└── dao/
    ├── tm_user_dao.go                ← DAO CRUD
    ├── tm_user_constant.go           ← 常量
    ├── tm_user_namingsql.go          ← 命名 SQL（通用）
    ├── mysql_tm_user_namingsql.go    ← MySQL 特定 SQL
    └── db2_tm_user_namingsql.go      ← DB2 特定 SQL（-d 指定时只生成一种）
```

### 1. Model 文件（`{table}_model.go`）

```go
package model

type TmUser struct {
    Seq  int64  `gorm:"column:SEQ;primaryKey;not null" json:"seq"`
    Name string `gorm:"column:NAME;not null" json:"name"`
    // ...
}

// 自动生成的方法
func (t *TmUser) TableName() string                               // 返回表名
func (t *TmUser) Clone() *TmUser                                   // 克隆
func (t *TmUser) ToString() string                                 // 格式化
func (t *TmUser) ListZeroValueCols(...) ([]string, []interface{}, error) // 列零值检查
var TmUserAllowUpdateCols = []string{...}                          // 可更新列
var TmUserIndexLeadingCols = []string{...}                         // 索引前导列

// 自定义查询相关（如有 self_query_rules）
type TmUserFindByNameArg struct { ... }          // 查询参数
func (a *TmUserFindByNameArg) WithName(...)       // 链式 With 方法
func (a *TmUserFindByNameArg) ConvertToMap()      // 转 map
type TmUserFindByNameRes struct { ... }           // 查询结果（指定字段时）
type TmUserFindByNamePageRes struct { ... }       // 分页结果（page=true 时）
```

**查询参数生成规则：**

| YAML 配置 | 生成的代码 |
|-----------|-----------|
| `page: true` | 参数结构体包含 `db.Page`，结果包含 `db.PageResult` |
| `page: false` | 无分页参数，返回列表 |
| `select_fields: "*"` | 使用主结构体作为结果类型，不生成 Res |
| `select_fields: "COL1,COL2"` | 生成仅含指定字段的 `{QueryName}Res` 结构体 |
| 普通 WHERE 条件 | 生成 `With{Field}()` 链式方法 |
| 动态模板 | 从 `Where_params` 生成参数结构体 |

### 2. DAO 文件（`{table}_dao.go`）

```go
package dao

import "gitlab.allinfinance.com/aifgo/ag-core/contribute/agdb/agdao"

type TmUserDao struct {
    *agdao.Dao   // 嵌入基础 DAO
}

func (d *TmUserDao) Get(ctx context.Context, entity *model.TmUser) (bool, error)
func (d *TmUserDao) Insert(ctx context.Context, entity *model.TmUser) error
func (d *TmUserDao) Update(ctx context.Context, entity *model.TmUser) error
func (d *TmUserDao) Delete(ctx context.Context, entity *model.TmUser) error
func (d *TmUserDao) BatchInsert(ctx context.Context, entities []*model.TmUser) error
func (d *TmUserDao) BatchUpdate(ctx context.Context, entities []*model.TmUser) error
```

**CRUD 方法逻辑：**

| 方法 | 实现要点 |
|------|---------|
| `Get` | 使用主键条件 + `ListZeroValueCols` 排除零值列 |
| `Insert` | 插入完整实体 |
| `Update` | 只更新 `AllowUpdateCols` 中的列 |
| `Delete` | 使用主键条件删除 |
| `BatchInsert` | 批量插入 |
| `BatchUpdate` | 批量更新 |

### 3. 常量文件（`{table}_constant.go`）

包含：
- 列名常量切片
- `AllowUpdateCols` 可更新列列表
- `IndexLeadingCols` 索引前导列列表  
- 命名 SQL 查询名 → SQL 映射
- 空值字段排除映射

### 4. 命名 SQL 文件（`{table}_namingsql.go`）

每个 `self_query_rules` 条目生成一条命名 SQL：

```go
var TmUserFindByNameNamedSql = "SELECT NAME, ADDRESS FROM TM_USER WHERE NAME = @Name"
var TmUserFindAllColsByPageNamedSql = "SELECT * FROM TM_USER WHERE ADDRESS = @Address"
```

### 5. 数据库特定 SQL（`{dbtype}_{table}_namingsql.go`）

处理数据库差异：

| 数据库 | 分页语法差异 |
|--------|-------------|
| MySQL | `LIMIT ? OFFSET ?` |
| DB2 | `FETCH FIRST ? ROWS ONLY` |

## 索引安全检查（Index Guard）

生成 DAO 前，工具会自动验证每个自定义查询的 WHERE 条件**至少命中一个索引或主键**：

1. **优先检查主键** — WHERE 条件包含主键列 → 通过
2. **检查索引引导列** — 未命中主键时，检查索引的**第一列**
3. **复合主键规则** — 命中非第一主键但未命中第一主键 → 警告
4. **未命中报错** — 阻止生成

```bash
# 触发错误示例
gen-go-db db -i ./repository/yaml/TM_USER.yaml -o ./
# 输出：查询 FindByAddress 的请求参数没有命中任何索引或主键
```

**解决方法**：为查询字段添加数据库索引，或调整查询条件包含索引列。

## 模块名自动发现

不指定 `-m` 时，工具自动读取当前目录 `go.mod`：

```go
// dao/generator.go:91-113
func getModuleName() string {
    // 读取 go.mod → 解析 "module xxx" 行
}
```

## 内部实现

| 组件 | 文件 | 职责 |
|------|------|------|
| 入口 | `dao/generator.go:GenerateDAOFromYAML` | 调度 YAML 解析 + 代码生成 |
| YAML 解析 | `dao/parser.go:YAMLParser` | 遍历 YAML 文件，调用 model.ParseYAML |
| Model 生成 | `model/template.go:GetModelTemplate` | 拼装 Model 代码 |
| DAO 生成 | `dao/template.go` | 拼装 DAO CRUD + 命名 SQL |
| 索引检查 | `model/generator.go:checkQueryArgsIndexes` | 验证查询命中索引 |
